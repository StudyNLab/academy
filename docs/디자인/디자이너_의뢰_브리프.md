## 1. 어떤 서비스인가요

**AIONIT(아이오닛)** 은 IT 인프라 · 정보보안 · AI 를 가르치는 온라인 교육 서비스입니다. 지금 개발 중이고, 오픈 전에 로고와 화면 디자인을 전문가에게 맡기려고 합니다.

- **배우는 것**: 리눅스 서버 운영 · 네트워크(인프라), 보안 관제 · 침해 대응(보안), LLM · AI Agent · 업무 자동화(AI)
- **누가 배우나요**: 한국의 직장인 · 취업 준비생 · IT 실무자. 개인이 돈을 내고 듣는 B2C 서비스입니다.
- **판매 방식**: 강의 단건 구매 + 월/연 구독. 여러 명의 현업 강사가 강의를 올립니다.
- **다른 곳과 다른 점**: 영상만 보는 강의가 아니라 **책처럼 다시 펼쳐 보는 교재**와 **실제 서버에서 해 보는 실습**이 함께 있습니다. 학습 화면은 오래 읽는 "교재 지면"이 중심입니다.

### 이름의 뜻

- **AIONIT = AI on IT.** 인프라 · 보안이라는 IT 의 바탕 *위에(on)* AI 를 얹는다는 뜻입니다.
- 읽는 법은 **아이오닛**. 영문 대문자 `AIONIT` 를 기본으로 씁니다.
- 영어로 *on* 은 "켜다"라는 뜻도 있어서, 지금 켜고 배우기 시작한다는 의미도 겹쳐 있습니다. 다만 이 뜻을 **전원 버튼 그림으로 그대로 그리는 것은 원하지 않습니다** (아래 4장).

## 3. 로고에 담고 싶은 것 (우선순위 순)

1. **읽히는 이름.** `AIONIT` 가 한눈에 한 단어로 읽혀야 합니다. 처음 본 사람이 "아이오닛"이라고 읽을 수 있으면 좋겠습니다.
2. **바탕 위에 얹는다(on)** 는 생각. 직접적인 그림보다 글자의 구조 · 비례 · 한 군데의 작은 변형으로 은근히 드러나면 좋습니다.
3. **작아도 선명함.** 브라우저 탭의 16px 아이콘, 휴대폰 앱 아이콘, 교재 PDF 머리말에서도 알아볼 수 있어야 합니다.
4. **한글과 함께 쓸 때 어울림.** 화면 대부분이 한글입니다. "아이오닛" 한글 표기와 나란히 놓여도 어색하지 않아야 합니다.

방향을 정해 드리지는 않습니다. 워드마크(글자만) · 심볼 + 워드마크 · 모노그램 등 형식은 디자이너님의 제안을 기다립니다.

## 4. 피해 주세요

IT · AI 교육 로고에서 너무 흔해서 구별이 안 되는 것들입니다.

- 로봇, 사람 얼굴 · 뇌, 회로 기판 선, 전구
- 네온 · 형광 그라데이션, 빛 번짐(glow), 3D 광택, 우주 · 은하
- **전원 버튼 기호(⏻)** — 지금 임시 로고가 이것이라 더 피하고 싶습니다
- 자물쇠 · 방패(보안), 구름(클라우드), 지구본, 육각형 그물, `</>` 기호
- 다른 유명 브랜드와 닮은 모양 (특히 이름 소리가 비슷한 **현대자동차 IONIQ(아이오닉)** 로고와 헷갈리지 않게)
- 생성형 AI(Midjourney 등)로 만든 이미지를 최종 로고로 쓰는 것 (5장 "원본성" 참고)

## 5. 받고 싶은 것 (기본 패키지)

### 5.1 로고

| 항목 | 내용 |
|---|---|
| 시안 | 서로 다른 방향 **3개 이상** (각 방향마다 한 줄 설명) |

| 심볼(아이콘)만 | 글자 없이 쓰는 표식. 파비콘 · 앱 아이콘 · SNS 프로필용 |
| 한글 병기형 | `AIONIT` + `아이오닛` 함께 쓰는 배치 1종 |

| 파비콘 · 앱 아이콘 | 16 · 32 · 48 · 180 · 192 · 512px PNG, `favicon.ico`, 단색 SVG (작은 크기는 따로 다듬은 것) |
| SNS · 공유 이미지 | 링크 공유용 1200×630 기본 이미지 1종 |

### 5.2 기본 브랜드 가이드 (PDF 10쪽 안팎이면 충분)

- 로고 구조와 의미 설명 (짧게)
- 주변 여백(clear space) · 최소 크기
- 색 — HEX / RGB, **라이트 · 다크 모드 각각**. 글자 색은 바탕과 명도 대비 4.5:1 이상 (웹 접근성 기준)
- 글꼴 — 로고에 쓴 글꼴과 화면용 글꼴 추천. **화면용 글꼴은 상업용 웹 사용이 무료인 것**(OFL 등)으로 부탁드립니다
- 잘못 쓴 예 (늘리기 · 색 바꾸기 · 그림자 넣기 · 회전 등) 6개 안팎
- 적용 예 2~3개 (웹사이트 머리글, 교재 PDF 표지, 수료증 정도)

### 5.3 파일

- **AI(Illustrator) 원본**, **SVG**(글자를 윤곽선으로 바꾼 것), PDF, PNG(투명 바탕)
- SVG 는 웹에 바로 쓸 수 있게 깔끔하게 (불필요한 그룹 · 숨은 레이어 · 이미지 삽입 없이, `viewBox` 정리)
- 폴더 정리: `logo/` · `symbol/` · `favicon/` · `guide/`

### 5.4 권리 · 원본성 (중요)

- **저작재산권 전부 양도** (2차적저작물 작성권 포함). 계약서 또는 플랫폼의 저작권 양도 옵션으로 문서로 남깁니다.
- **상표 출원이 가능하도록** 직접 창작한 것이어야 합니다.
  - 기존 로고 · 무료 아이콘 · 템플릿 · 유료 스톡을 가져다 쓰지 않습니다.
  - 생성형 AI 이미지를 최종 로고에 쓰지 않습니다 (아이디어 참고는 괜찮지만, 최종 형태는 직접 그린 것이어야 합니다). AI 생성물은 저작권 · 상표 등록에서 문제가 될 수 있습니다.
  - 로고 글자에 기존 글꼴을 썼다면, 그 글꼴의 **로고 사용 · 상업 사용 허용** 여부를 알려 주세요 (윤곽선으로 바꾼 뒤 손본 것이면 더 좋습니다).
- 작업 과정(스케치 · 중간 단계) 파일을 일부 보여 주시면, 직접 창작했다는 근거로 보관하겠습니다.
- 포트폴리오 게시는 **오픈 이후**에는 괜찮습니다. 오픈 전에는 공개하지 말아 주세요.

## 6. 선택 추가 의뢰: 핵심 화면 UI 디자인 (Figma)

로고 작업과 함께, 또는 로고가 끝난 뒤 이어서 맡아 주실 수 있으면 별도 견적을 부탁드립니다.
화면 구성(와이어프레임)과 기능 정의는 이미 있습니다. **보기 좋게 다듬고, 개발자가 그대로 옮길 수 있게 정리**하는 일입니다.

| 화면 | 내용 |
|---|---|
| 홈 | 서비스 소개, 분야 3개, 강의 목록 일부, 구독 안내 |
| 강의 목록 | 분야 · 수준으로 거르기, 줄 목록 형태 |
| 강의 상세 | 소개 · 목차 · 강사 · 가격 · 구매 버튼 |
| **학습 화면** | 목차 · 교재 본문 · 영상 · 코드 블록 · 실습 체크 · 여백 메모. **가장 중요한 화면** (라이트 · 다크 둘 다) |
| 로그인 / 회원가입 | 이메일 · 구글 로그인 |
| 마이페이지 | 수강 중인 강의 · 구독 상태 · 결제 내역 |
| 모바일 | 위 화면 중 홈 · 강의 상세 · 학습 화면의 모바일 버전 |

받고 싶은 것:

- Figma 파일 (데스크톱 1440 · 모바일 390 기준), **Auto Layout** 으로 만든 것
- 색 · 글꼴 · 간격을 **Figma Variables(또는 Styles)** 로 정리 — 라이트 · 다크 모드 두 벌
- 공통 부품(Component) 정리: 버튼 · 입력창 · 상태 표시 · 진도 막대 · 강의 줄 · 목차 · 코드 블록 · 여백 메모 · 표 · 알림 · 확인 창
- 부품마다 기본 · 마우스 올림 · 눌림 · 비활성 · 오류 상태
- 개발은 Tailwind CSS 로 합니다. 간격은 4px 단위, 모서리 · 그림자 값을 숫자로 정해 주시면 됩니다.
- 접근성: 글자 대비 4.5:1 이상, 누르는 영역 최소 44×44px, 색만으로 상태를 구분하지 않기

## 7. 일정

## 짧은 버전 (글자 수 제한이 있는 곳용)

> IT 인프라 · 정보보안 · AI 온라인 교육 서비스 **AIONIT(아이오닛, "AI on IT")** 의 로고와 기본 브랜드 가이드를 의뢰합니다.
> 한국 직장인 · 실무자가 대상이고, 책 · 기술 문서처럼 **차분하고 전문적인** 느낌을 원합니다. 로봇 · 회로 · 뇌 · 전구 · 네온 그라데이션 · 전원 버튼 기호는 피해 주세요.
> **받을 것**: 시안 3개 이상 · 수정 3회 이상, 기본형 · 가로형 · 세로형 · 심볼 · 한글 병기형, 컬러 · 흑백 · 반전, 파비콘 · 앱 아이콘, AI · SVG · PDF · PNG 원본, 간단한 브랜드 가이드(색 · 글꼴 · 여백 · 잘못 쓴 예).
