## 1. 지금 디자인을 솔직하게 보면

방향(A-2, 차분한 전문성 · 책 같은 화면)은 맞다. 문제는 **만듦새**다. 무엇이 "아마추어 같다", "AI 가 만든 것 같다" 는 인상을 주는지 정리했다.

### 1.1 로고

| 문제 | 왜 아마추어처럼 보이나 |
|---|---|
| 전원 기호(⏻)를 O 자리에 | 국제 표준 기호(IEC 5009)를 그대로 가져온 것. 누구나 쓸 수 있는 모양이라 **우리 것이 되지 않고**, 상표로서 구별력도 약하다. "on = 전원" 은 가장 먼저 떠오르는 답이라 뻔하다. |
| 글꼴을 친 글자 + 아이콘 | `AI` `NIT` 는 본문 글꼴(IBM Plex Sans KR Bold)을 그대로 쳤다. 로고 글자를 손보지 않으면 "이름을 써 놓은 것" 이지 로고가 아니다. |
| 선 두께 · 끝 모양이 글자와 다름 | 전원 기호는 선(stroke)이고 글자는 면(fill). 두께 · 끝 처리 · 시각적 크기가 맞지 않아 끼워 넣은 티가 난다. 위치도 `margin 0.035em` 같은 값으로 눈대중 맞춤. |
| 가운데만 다른 색 | O 만 주황이라 `AI · ⏻ · NIT` 로 끊겨 보인다. "아이오닛" 한 단어로 읽히지 않는다. |
| 작은 크기 | 16px 심볼은 남색 상자 안에 두 색 선이 뭉개진다. 작은 크기용으로 따로 다듬은 버전이 없다. |
| 이름 혼용 | 시안 A-2 머리글은 "온라인아카데미", 나머지는 AIONIT. 브랜드가 한 번도 정해진 적 없는 상태로 보인다. |

### 1.2 화면

| 문제 | 설명 |
|---|---|
| **"AI 가 만든 편집 디자인" 의 정형** | 미색 종이 바탕 + 남색 + 테라코타 한 색 + 가는 선 + `01 · 02 · 03` 3단 + 고정폭 대문자 라벨. 지금 AI 도구들이 "고급스럽게" 를 요청받으면 거의 항상 내는 조합이다. 하나하나는 좋은 선택인데, 전부 같이 있으면 정형으로 읽힌다. |
| 한글 화면의 영어 라벨 | `How it works` · `Subscription` · `For instructors` · `01 · Infra`. 내용과 상관없는 영어 대문자 라벨이 구역마다 붙어 있다. 꾸밈으로만 쓰인 티가 난다. |
| 모든 구역이 같은 리듬 | 라벨 → 큰 제목 → 회색 문단 → 선 목록, 이 순서가 구역마다 반복된다. 강약 · 크기 변화 · 이미지가 없어 길게 내릴수록 지루하다. |
| 진짜 그림이 없다 | 강사 사진, 실제 학습 화면 캡처, 실습 터미널, 수료증 같은 **이 서비스만의 증거**가 없다. 교재 그림 한 장이 전부. 빈 자리를 선과 여백으로만 채웠다. |
| 굵기 하나 · 글꼴 하나 | 제목은 전부 600, 본문은 300~400. 한글 Plex 300 을 회색(#4A5361)으로 미색 위에 쓰면 흐리고 얇아 보인다. 제목용 글꼴의 개성이 없다. |
| 한글 자간 | 제목에 −4% 자간. 영문에서는 단단해 보이지만 한글 큰 제목에서는 받침끼리 붙어 답답해진다. |
| 자리표시 | `[강사 이름]` `[가격]원` `[n]장` 이 화면 곳곳에 있어 견본(템플릿)처럼 보인다. (콘텐츠가 생기면 해결) |
| 세부 상태 | 마우스 올림 · 눌림 · 로딩 · 빈 목록 · 오류 화면이 디자인되지 않았다. 실제로 써 볼 때 "덜 만든" 느낌은 대부분 여기서 온다. |
| 기본 자산 없음 | 파비콘 · 앱 아이콘 · 링크 공유 이미지(OG)가 코드에 없다. 메일 템플릿은 색을 직접 적어 둠. |

### 1.3 그래서

- **유지할 것**: 방향(차분한 전문성), 교재 중심 학습 화면 구조, 토큰 체계(CSS 변수 → Tailwind), 접근성 기준(대비 4.5:1, 44px), 줄 목록 · 여백 메모 같은 부품 설계.
- **바꿀 것**: 로고 전부, 색 값(디자이너 제안에 따라), 제목 글꼴 · 굵기 · 자간, 구역 리듬, 실제 사진 · 캡처 쓰는 법, 세부 상태.
- 토큰 체계를 이미 만들어 두었기 때문에, 디자이너 결과물이 오면 **값만 바꾸면 화면 전체가 따라 바뀐다.** 다시 짤 필요는 없다.

## 2. 의뢰 전에 정할 것 — 이름 (운영자 결정)

로고를 맡긴 뒤 이름이 바뀌면 로고 비용을 다시 낸다. 의뢰 **전에** 이름을 확정한다.

- **소리가 현대자동차 IONIQ(아이오닉)와 비슷하다.** 분야(교육 41류 vs 자동차 12류)가 달라 바로 문제가 되지는 않을 수 있지만, 유명 상표는 다른 분야에서도 보호받는 경우가 있다.
- 확인 방법: [KIPRIS](https://www.kipris.or.kr) 에서 `AIONIT` · `아이오닛` · `AION` 을 41류(교육) · 9류(소프트웨어) · 42류(IT 서비스)로 검색. 마음이 놓이지 않으면 변리사 상담(상표 검색 · 출원 대행, 보통 수십만 원대)을 한다.
- 이름을 바꾸면 브리프 1장 "이름의 뜻" 과 로고 프롬프트의 `AIONIT` 만 바꾸면 된다.

**어디에 올릴까**

| 곳 | 방식 | 맞는 경우 |
|---|---|---|
| **크몽** | 디자이너 상품을 고르거나 "프로젝트 의뢰"로 견적 받기 | 포트폴리오를 보고 **한 사람을 골라** 대화하며 진행. 가장 추천. |
| **라우드소싱** | 콘테스트 — 상금을 걸면 여러 디자이너가 시안을 낸다 | 시안을 많이 보고 싶을 때. 품질 차이가 크고, 뽑힌 1개만 저작권 양도. UI 추가 의뢰에는 안 맞음. |
| **숨고** | 요청서를 올리면 고수들이 견적을 보냄 | 크몽과 함께 견적 비교용. 짧은 버전 브리프를 쓴다. |

**고를 때** (브리프 10장 기준에 더해)

- 포트폴리오에 **글자를 손본 워드마크**가 있는가 — 아이콘만 잘 그리는 사람은 피한다.
- 한 사람이 로고와 UI 를 둘 다 잘하는 경우는 드물다. UI 는 로고가 끝난 뒤 **다른 사람**에게 맡겨도 된다.
- 계약서(또는 플랫폼 옵션)에 **저작재산권 양도 · 2차적저작물 작성권 · 생성형 AI 미사용**이 적혀 있는지 확인.

### 단계 2 · M3(학습 화면) 즈음 — Tailwind Plus 구매 검토 (운영자 결정)

**Tailwind Plus**(옛 이름 Tailwind UI)는 Tailwind 를 만든 회사가 파는 화면 부품 · 견본 모음이다. 한 번 사면 계속 쓰는 방식(개인 약 $299, 팀 약 $979 — 살 때 가격 확인).

| | 내용 |
|---|---|
| 얻는 것 | 잘 다듬은 화면 조각(목록 · 폼 · 표 · 설정 화면 · 빈 상태 등) 수백 개, React 부품 모음 **Catalyst**, 견본 사이트. **운영자 · 강사 화면**처럼 디자이너를 따로 쓰기 아까운 화면을 빠르게 단정하게 만들 수 있다. |
| 맞지 않는 점 | 기본 모양이 둥근 모서리 · 회색(zinc) · 카드 중심이라 우리 A-2 원칙(각진 모서리 · 선 · 카드 안 씀)과 다르다. 그대로 쓰면 **또 다른 "흔한 Tailwind 사이트"** 가 된다. |
| 공짜로 되는 부분 | 열고 닫기 · 키보드 조작 같은 동작은 **Headless UI**(무료, MIT)만으로 된다. Tailwind Plus 는 주로 "모양" 을 산다. |
| 판단 기준 | M3 를 만들면서 운영자 · 강사 화면(AD-*, I-*)을 짤 때 시간이 많이 들면 산다. 디자이너가 UI 까지 맡으면 학습자 화면에는 거의 필요 없다. |
| 산다면 쓰는 법 | Catalyst 부품을 `packages/ui` 로 가져와 **색 · 모서리 · 그림자를 우리 토큰으로 바꿔 칠한다**: `zinc-*` → `ink` · `line` · `sunken`, `rounded-lg` → `rounded-ui`, `shadow-*` → `shadow-float`, `dark:` 대신 CSS 변수(이미 다크 모드 지원). 부품 하나씩 바꿔 넣고, 화면 코드는 고치지 않는다. |
| 라이선스 주의 | 우리 서비스 안에서 쓰는 것은 된다. 부품을 그대로 묶어 남에게 파는 것(UI 키트 재판매)은 안 된다. 저장소가 공개되면 안 되는지 살 때 약관을 다시 확인한다. |

**추천**: 디자이너에게 UI 까지 맡기기로 하면 **사지 않는다.** 로고만 맡기고 화면은 Claude 가 계속 만들기로 하면, M3 운영자 화면 작업 전에 산다.

### 단계 3 · 오픈 전 — 디자이너 결과물 반영

디자이너에게서 로고 파일 · 브랜드 가이드 · (선택) Figma 를 받으면 Claude 가 아래 순서로 바꾼다. 화면 구조는 그대로 두고 **토큰 → 로고 → 부품 → 화면** 순으로 바꾸기 때문에, 중간에 멈춰도 사이트는 깨지지 않는다.

#### ① 토큰 (색 · 글꼴 · 간격)

| 바꿀 곳 | 무엇을 |
|---|---|
| `packages/ui/src/tokens.css` | `:root` 와 다크 모드 두 곳(`@media` 안, `[data-theme="dark"]`)의 색 값. Figma Variables 이름을 우리 토큰 이름(`--bg` `--ink` `--primary` `--signal` …)에 맞춰 옮긴다. 새 토큰이 필요하면 `@theme inline` 에도 더한다. `--radius-ui`, `--shadow-float`, `--font-sans` · `--font-mono` 도 여기. |
| `docs/디자인시스템.md` 2장 | 표의 값을 같이 고친다 (문서가 개발 기준). |
| `apps/web/src/app/layout.tsx` | 글꼴이 바뀌면 `@fontsource/*` import 를 바꾸고(`pnpm add`), `viewport.themeColor` 두 색을 새 바탕색으로. |
| `packages/mail/src/templates.ts` | 메일 HTML 에 직접 적힌 바탕 · 글자 · 버튼 색(`#f6f5f1` `#121a26` `#18304f`). 메일은 CSS 변수를 못 써서 값을 직접 바꾼다. |

검사: 모든 글자 색 조합이 4.5:1 이상인지 확인하는 작은 스크립트를 돌린다 (라이트 · 다크).

| `packages/ui/src/Wordmark.tsx` | 글꼴로 친 `AI`+`PowerIcon`+`NIT` 를 지우고, 디자이너 SVG 를 그대로 넣은 `Logo`(가로형) · `LogoSymbol`(심볼) 부품으로 바꾼다. 색은 `currentColor` · CSS 변수로 받게 해서 라이트 · 다크에 자동으로 맞춘다. 이름은 `Wordmark` 를 남겨 두면 쓰는 곳을 안 고쳐도 된다. |
| `packages/ui/src/index.ts` | `PowerIcon` export 를 빼고 새 부품을 export. |
| `apps/web/src/components/site-chrome.tsx` | 머리글 · 바닥글의 `<Wordmark />` (크기만 확인). |

| `docs/디자인시스템.md` 3장 | "임시 브랜드" 를 지우고 가이드 요약 · 여백 · 최소 크기 · 잘못 쓴 예 링크. |
| 디자이너 원본 | `docs/디자인/브랜드/` 에 SVG · PDF 가이드 보관 (AI 원본은 용량이 크면 저장소 밖 보관 + 위치만 적기). |

#### ③ 부품 (Figma 를 받은 경우)

`packages/ui/src` 의 부품을 Figma Component 와 하나씩 맞춘다. 지금 있는 것은 `Button.tsx` · `Field.tsx` · `Status.tsx` 이고, 디자인시스템.md 6장 목록(ProgressBar · CourseRow · Toc · CodeBlock · MarginNote · VideoPlayer · SelfCheck · DataTable · Toast · Dialog)은 M2 · M3 에서 만들어지는 대로 맞춘다.

- 높이 · 여백 · 글자 크기 · 상태(기본 · 올림 · 눌림 · 비활성 · 오류)를 Figma 값 그대로.
- 부품의 바깥 모양(props)은 바꾸지 않는다 → 화면 코드를 안 고쳐도 된다.

#### ④ 화면

| 화면 | 파일 |
|---|---|
| 홈 | `apps/web/src/app/(public)/page.tsx` |
| 로그인 · 가입 · 비밀번호 | `apps/web/src/app/(auth)/*` |
| 마이페이지 | `apps/web/src/app/(my)/my/*` |
| 강의 목록 · 상세 · 학습 화면 | M2 · M3 에서 생기는 `apps/web/src/app/(public)/courses/*`, `/learn/*` |
