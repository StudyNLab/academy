# AIONIT 로고 방향 탐색 — AI 이미지 프롬프트 (Ideogram · Recraft)

- 작성: 2026-11-04
- 목적: **방향을 찾고, 디자이너에게 "이런 쪽" 을 보여 줄 참고 그림**을 만드는 것. 최종 로고가 아니다.

## 0. 먼저 알아 둘 것 — 왜 AI 로 최종 로고를 만들지 않나

| 이유 | 설명 |
|---|---|
| 저작권 | 한국 · 미국 모두 사람이 창작하지 않은 부분은 저작물로 보호받기 어렵다. 남이 비슷한 것을 써도 막기 힘들다. |
| 상표 | AI 는 학습한 기존 로고와 닮은 모양을 자주 만든다. 출원했다가 유사 상표로 거절되거나 분쟁이 날 수 있다. |
| 품질 | 16px 파비콘 · 1도 인쇄 · 정확한 자간 같은 실제 쓰임을 AI 가 맞추지 못한다. 결국 벡터로 다시 그려야 한다. |
| 약관 | 무료 요금제는 만든 그림이 공개 갤러리에 올라가거나 상업 이용 조건이 붙는 경우가 있다. |

그래서 이렇게 쓴다.

1. 아래 프롬프트로 방향마다 몇 장씩 만든다.
2. 마음에 드는 **방향**(형태가 아니라 생각)을 2~3개 고른다.
3. 고른 그림을 디자이너에게 "이 방향의 느낌" 참고로만 보낸다. **"이걸 그대로 다듬어 주세요"라고 하지 않는다.**
4. 만든 그림은 `docs/디자인/참고/` 에 날짜와 함께 저장해 둔다 (나중에 "디자이너 결과물이 AI 그림을 베낀 게 아니다"를 보여 주는 근거도 된다).

> 이 단계는 **건너뛰어도 된다.** 디자이너가 시안 3개를 직접 탐색하기 때문에, 이 작업은 "내가 뭘 좋아하는지 미리 알아 두기" 정도의 의미다.
> 두 서비스 모두 회원가입이 필요해서 Claude 가 대신 할 수 없다. 무료 요금제로 충분하다.

## 1. 공통 설정

### 꼭 넣는 말 (스타일)

```
minimal logo, flat vector, solid shapes, no gradients, no shadows, no 3D,
editorial, calm, professional, Swiss typography, generous negative space,
plain off-white background #F6F5F1, ink color #121A26, single accent #B4492D
```

### 꼭 빼는 말 (Negative prompt)

Ideogram 은 Negative prompt 칸에, Recraft 는 프롬프트 끝에 `avoid:` 로 붙인다.

```
robot, circuit board, brain, neural network nodes, light bulb, power button symbol,
neon, glow, gradient, 3D, glossy, galaxy, shield, padlock, cloud, globe, hexagon mesh,
code brackets, mascot, cartoon, clip art, photorealistic, mockup, multiple colors
```

### 서비스별 설정

| | Ideogram (ideogram.ai) | Recraft (recraft.ai) |
|---|---|---|
| 잘하는 것 | **글자가 들어간 로고** — `AIONIT` 철자를 비교적 정확히 씀 | **벡터(SVG)로 받기**, 심볼 · 아이콘 |
| 모델 · 스타일 | 최신 모델, Style = **Design** | Style = **Vector art → Line art / Logo** 또는 **Icon** |
| Magic Prompt | **끄기** (켜면 멋대로 장식을 더함) | 해당 없음 |
| 비율 | 워드마크 3:1, 심볼 1:1 | 1:1 |
| 색 | Color palette 에 `#121A26` `#B4492D` `#F6F5F1` 지정 | Colors 에 같은 세 색 지정 |
| 한 번에 | 4장 | 2~4장 |

## 2. 방향별 프롬프트

방향마다 **영어 프롬프트를 그대로 복사**해서 쓴다. 한국어 설명은 무엇을 보려는 것인지 적은 것이다.

### 방향 1 · 순수 워드마크 — 손본 글자 하나

> 글꼴을 친 것처럼 보이지 않게, 글자 하나(주로 O)에만 작은 변형. 가장 무난하고 오래 가는 방향.

**Ideogram**
```
A minimal wordmark logo that reads "AIONIT" in custom geometric sans-serif capitals,
tight but even letter spacing, the letter O is subtly modified with a small flat cut at the top
like a page resting on a line, all letters in ink color #121A26, the modification in #B4492D,
flat vector, editorial, calm, professional, plain off-white background #F6F5F1
```

**Recraft** (글자는 약하므로 O 한 글자만)
```
a single capital letter O for a logo, geometric, thick even stroke, a small flat cut at the top,
minimal flat vector, ink #121A26 on off-white #F6F5F1, Swiss style, no decoration
```

### 방향 2 · 바탕 위에 얹다 (on) — 기준선

> "IT 의 바탕 위에 AI" 를 **가로 기준선 + 그 위에 놓인 형태**로. 책의 밑줄 · 서가 · 지층 같은 느낌.

**Ideogram**
```
A minimal logo for "AIONIT", the wordmark sits on a single thick horizontal baseline
that extends slightly beyond the letters, as if the letters rest on a foundation,
geometric sans-serif capitals, ink #121A26, the baseline in #B4492D,
flat vector, editorial book-cover typography, plain off-white background #F6F5F1
```

**Recraft** (심볼)
```
abstract logo symbol: a solid square block resting on a thicker horizontal bar,
the block slightly offset to the right, two flat shapes only, foundation and layer concept,
minimal flat vector, ink #121A26 and accent #B4492D on off-white #F6F5F1, no text
```

### 방향 3 · 두 개의 I — 대칭과 구조

> `A I O N I T` 에는 I 가 두 번 나온다. 두 I 를 같은 기둥으로 맞춰 **구조물 · 서버 랙 · 기둥** 느낌을 은근히.

**Ideogram**
```
A minimal wordmark "AIONIT" where both letters I are drawn as identical tall vertical pillars,
slightly taller than the other letters, creating a calm symmetrical rhythm,
custom monoline geometric capitals, ink #121A26, flat vector, architectural, editorial,
plain off-white background #F6F5F1
```

### 방향 4 · 모노그램 — A 와 기준선

> 파비콘 · 앱 아이콘을 먼저 생각한 방향. 글자 없이도 알아볼 표식.

**Recraft**
```
monogram logo of the capital letter A built from two thick strokes standing on a horizontal baseline,
the crossbar replaced by a small square, geometric, solid flat shapes,
works at 16 pixels, ink #121A26 on off-white #F6F5F1, accent square #B4492D, no text
```

**Ideogram**
```
A monogram app icon: a geometric capital letter A standing on a baseline, inside a square
with sharp corners, navy #18304F background, off-white #F6F5F1 letter, one small accent #B4492D,
flat vector, minimal, readable at very small size
```

### 방향 5 · 교재 지면 — 펼친 페이지

> 이 서비스의 차별점인 "교재". 책 · 페이지를 **아주 단순한 기하 도형**으로. 너무 직접적이면 흔해지니 조심.

**Recraft**
```
abstract logo symbol: two thin rectangles like open pages, one slightly raised above the other,
seen straight on, geometric, flat, minimal, editorial publishing brand,
ink #121A26 with one accent edge #B4492D on off-white #F6F5F1, no text, no book cliché
```

### 방향 6 · 커서 (주의해서)

> 실습(터미널)을 떠올리게 하는 **사각 커서**. 개발자 서비스에서 흔하므로 아주 절제했을 때만 의미가 있다. 다른 방향과 비교용.

**Ideogram**
```
A minimal wordmark "AIONIT" in custom geometric capitals, followed by a small solid
rectangular text cursor in #B4492D placed on the baseline, no brackets, no code symbols,
ink #121A26, flat vector, calm, editorial, plain off-white background #F6F5F1
```

## 3. 한글 병기 확인용

방향이 좁혀지면 한글과 함께 놓았을 때를 본다. (AI 는 한글을 자주 틀리게 쓰므로, 글자보다 **무게 · 비례가 어울리는지**만 본다.)

**Ideogram**
```
A horizontal logo lockup: the wordmark "AIONIT" in geometric capitals on the left,
a thin vertical rule, and the Korean text "아이오닛" in a clean modern sans-serif on the right,
matching visual weight, ink #121A26 on off-white #F6F5F1, flat vector, minimal
```

## 4. 고를 때 보는 것

만든 그림은 아래 질문으로 거른다. 3개 이상 "아니오" 면 버린다.

- [ ] 처음 보는 사람이 `AIONIT` 한 단어로 읽을 수 있나 (AI-ONIT, AION-IT 로 끊기지 않나)
- [ ] 흑백 1도로 바꿔도 성립하나
- [ ] 손톱만 하게 줄여도(16~32px) 형태가 남나
- [ ] "AI 스타트업" 로고 100개 사이에 섞여도 구별되나
- [ ] 다른 유명 로고, 특히 **현대 IONIQ** 로고가 떠오르지 않나
- [ ] 교재 PDF 표지 · 수료증에 찍혀도 차분해 보이나

## 5. 디자이너에게 보낼 때 쓰는 말

```
아래는 방향을 설명하려고 AI 로 만든 참고 이미지입니다. 형태를 따라 달라는 뜻이 아니라,
"이런 생각(예: 바탕 위에 얹는 기준선)" 이 마음에 든다는 뜻입니다.
최종 로고는 직접 창작해 주시고, 이 이미지와 닮지 않아도 됩니다.
```
