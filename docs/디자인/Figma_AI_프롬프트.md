## 0. 쓰는 법

| 도구 | 위치 | 받는 것 | 이럴 때 |
|---|---|---|---|
| **First Draft** | Figma Design 파일 → 아래 툴바 Actions(✦) → First Draft | 고칠 수 있는 Figma 레이어(프레임) | 디자이너에게 넘길 **편집 가능한 화면**이 필요할 때 — 추천 |
| **Figma Make** | figma.com → Make 새로 만들기 | 클릭되는 시제품(코드) | 화면을 눌러 보며 흐름을 확인하고 싶을 때 |

1. **① 공통 프롬프트**를 먼저 붙여 넣고, 이어서 **② 화면별 프롬프트**를 **한 화면씩** 요청한다. 한 번에 7개를 요청하면 화면마다 품질이 크게 떨어진다.
2. 첫 화면(홈)이 마음에 들 때까지 고친 다음, "앞 화면과 같은 스타일로" 를 붙여 다음 화면을 요청한다.
3. 결과가 이상하면 **③ 고칠 때 쓰는 말**을 쓴다.
4. 받은 화면은 디자이너에게 "구성 참고용" 으로만 보낸다. 로고는 넣지 않고 글자 `AIONIT` 로 둔다 (로고는 디자이너가 만든다).

## ① 공통 프롬프트 (맨 처음 한 번)

```
너는 한국 IT 교육 서비스의 시니어 프로덕트 디자이너야. 아래 서비스의 화면을 "디자인이 들어간 와이어프레임" 수준으로 만들어 줘. 실제 서비스처럼 보이되, 장식보다 정보 구조와 타이포그래피가 좋아야 해.

[서비스]
- 이름: AIONIT (아이오닛, "AI on IT"). IT 인프라 · 정보보안 · AI 온라인 강의 서비스.
- 대상: 한국 직장인, IT 실무자, 취업 준비생. 개인이 결제하는 B2C.
- 판매: 강의 단건 구매 + 월/연 구독. 여러 현업 강사가 강의를 올린다.
- 차별점: 영상 + 책처럼 읽는 교재 + 실제 서버 실습과 "스스로 확인" 체크리스트. 학습 화면은 오래 읽는 교재 지면이 중심.

[톤]
차분한 전문성. 잘 만든 기술 서적 · 기술 문서 같은 화면. Stripe 문서, Linear, O'Reilly 책의 차분함. 화려함보다 읽기 편함과 신뢰감.

[디자인 규칙]
- 색: 바탕 #F6F5F1, 흰 면 #FFFFFF, 글자 #121A26, 보조 글자 #4A5361, 가는 선 #DAD7CF, 주 버튼 · 링크 남색 #18304F, 강조색은 #B4492D 하나만 (번호 · 현재 위치 · "무료 공개"에만 아주 조금). 완료 #2E6B4A, 주의 #8A5A00, 오류 #A3302B.
- 글꼴: 한글 · 영문 모두 IBM Plex Sans KR, 번호 · 코드는 IBM Plex Mono.
- 글자 크기: 홈 큰 제목 56~64, 페이지 제목 40~48, 구역 제목 28~32, 목록 제목 20~22, 교재 본문 17 (줄 간격 1.8), 버튼 · 목록 15, 설명 13.
- 한글 제목은 자간을 0 ~ -1% 로만 (너무 좁히지 않기). 제목 굵기는 600~700, 본문 400.
- 구역은 카드 · 상자 대신 1px 가는 선과 여백으로 나눈다. 모서리는 2px 로 거의 각지게. 그림자는 떠 있는 것(메뉴 · 창)에만.
- 격자: 데스크톱 1440 폭, 콘텐츠 최대 1296, 좌우 여백 56, 12칸. 모바일 390 폭, 좌우 여백 20. 간격은 4의 배수.
- 한 화면에 채운 버튼(주 행동)은 하나. 나머지는 외곽선 버튼이나 밑줄 글 링크.
- 상태는 색만으로 표시하지 않고 작은 사각 점 + 글자로 (● 이용 중).
- 누르는 영역은 최소 44×44.

[하지 말 것]
- 로고를 새로 그리지 말 것. 로고 자리는 굵은 글자 "AIONIT" 만.
- 로봇, 뇌, 회로, 전구, 네온, 그라데이션, 3D, 빛 번짐, 이모지 아이콘.
- 둥근 카드를 격자로 늘어놓기, 색 배지 · 칩 남발.
- 한글 화면에 꾸밈용 영어 라벨(How it works, Features 같은 것) 붙이기. 라벨이 필요하면 한글로.
- 모든 구역을 "작은 라벨 → 큰 제목 → 회색 문단" 같은 순서로 똑같이 반복하기. 구역마다 크기 · 배치에 강약을 줄 것.
- Lorem ipsum. 글은 아래 화면별 내용의 한국어를 쓰고, 없는 값은 [강사 이름]처럼 대괄호로.

[이미지]
사진 자리는 회색 상자 + 무엇이 들어갈지 한 줄(예: "강사 사진", "실습 터미널 화면 캡처"). 꾸밈용 일러스트는 넣지 않는다.

이해했으면 먼저 데스크톱 홈 화면부터 만들어 줘.
```

## ② 화면별 프롬프트

각 화면 요청 끝에 `앞 화면과 같은 색 · 글꼴 · 간격 규칙으로.` 를 붙인다.

### P-01 홈 (데스크톱 1440)

```
홈 화면을 만들어 줘. 위에서 아래로:
1. 머리글: 왼쪽 "AIONIT", 가운데~오른쪽 메뉴 [강의, 구독, 강사], 오른쪽 끝 [로그인] 글 링크와 채운 버튼 [무료로 시작하기].
2. 첫 화면: 큰 제목 "IT의 바탕 위에, AI를 켜다." / 소개 "인프라 · 보안 · AI를 현업 강사에게. 영상으로 개념을 잡고, 다시 펼쳐 보는 교재로 정리하고, 실습 기준으로 스스로 확인합니다." / 버튼 [강의 보기](채운 버튼), "구독으로 전부 듣기 →"(글 링크). 오른쪽에는 실제 학습 화면 캡처 자리 (교재 본문 + 코드 블록이 보이는 화면) 를 크게.
3. 분야 3개: 인프라(리눅스 서버 운영, 로그 관리, 네트워크) / 보안(보안 관제, SIEM, 침해 대응) / AI(LLM API, AI Agent, 업무 자동화). 카드가 아니라 가는 세로선으로 나눈 3단, 각 끝에 "인프라 강의 →" 같은 글 링크.
4. 강의 목록 미리보기: 제목 "지금 열린 강의", 오른쪽에 분야 탭 [전체 · 인프라 · 보안 · AI]. 카드가 아니라 줄 목록 3줄 — 각 줄: 번호 | 강의 이름 + 한 줄 소개 + 강사 | 분야 · 수준 | 구성(6장 · 실습 12) | 수강 방법("구독 포함 / 단건 [가격]원" 또는 "프리미엄 / 구독자 [n]% 할인"). 첫 강의: "AI Agent 개발 · 초급 — LLM API 호출부터 도구 호출, Agent 루프, 대화 기억까지".
5. 공부하는 방법: "보고, 읽고, 직접 확인한다." 영상 → 교재 → 실습 세 단계. 실습 단계 옆에 "스스로 확인" 체크리스트 일부를 실제 화면처럼 보여 줄 것.
6. 강사 소개 띠: 강사 사진 자리 2~3명 + 이름 · 현직 · 강의 이름.
7. 구독 안내: 남색(#18304F) 바탕 띠. "구독 하나로, 구독 포함 강의 전부." 월간 [월 요금]원 / 연간 [연 요금]원(월 [n]원꼴) 두 칸, 버튼 [구독 알아보기].
8. 강사 모집 한 줄: "현업의 지식을 강의로 만드세요." + 외곽선 버튼 [강사 지원하기].
9. 바닥글: 사업자 정보 자리, 공지 · 자주 묻는 질문 · 이용약관 · 개인정보처리방침(굵게) · 환불 정책.
```

### P-02 강의 목록 (데스크톱)

```
강의 목록 화면을 만들어 줘.
- 제목 "강의", 아래에 거르기: 분야 [전체 · 인프라 · 보안 · AI], 수준 [입문 · 초급 · 중급], 수강 방법 [구독 포함 · 프리미엄 · 무료 공개], 정렬 [최신순 · 인기순].
- 목록은 카드 격자가 아니라 표처럼 정렬된 줄 목록 8줄. 열: 번호(Mono, 강조색) | 강의 이름(굵게 20) + 한 줄 소개 + 강사 | 분야 · 수준 | 구성(n장 · 실습 n) | 수강 방법. 줄 사이 가는 선, 마우스를 올리면 바탕이 #EFEDE7.
- 결과가 없을 때 빈 화면도 하나 따로: "조건에 맞는 강의가 없습니다" + "거르기 지우기" 링크.
```

### P-03 강의 상세 (데스크톱)

```
강의 상세 화면을 만들어 줘. "AI Agent 개발 · 초급" 강의.
- 왼쪽 넓은 단: 분야 · 수준 표시, 강의 제목(44), 한 줄 소개, 강사 이름 · 현직. 맛보기 영상 자리(16:9, 가운데 재생 버튼, 아래 "무료 공개"). 
- 이 강의에서 하는 것 (실습 결과물 위주로 4~5줄).
- 목차: 6장. 각 장은 번호(Mono) + 제목 + 절 수 + 실습 수, 펼치면 절 목록. 무료 공개 절에는 강조색 글자 "무료 공개".
- 실습 환경 설명: 실제 서버 터미널 화면 캡처 자리 + "제공 실습 서버에서 바로 따라 합니다".
- 강사 소개: 사진 자리 + 경력 3줄.
- 자주 묻는 질문 3개 (펼침).
- 오른쪽 좁은 단(스크롤해도 따라오는 구매 패널, 흰 면 + 그림자): 구독 포함 표시, 단건 가격 [가격]원, 채운 버튼 [구매하기], 글 링크 "구독으로 듣기 →", 구성(6장 · 실습 12 · 영상 [n]시간), 수강 기간.
```

### L-02 학습 화면 (데스크톱 · 라이트) — 가장 중요

```
가장 중요한 학습 화면을 만들어 줘. 오래 읽어도 피곤하지 않은 "교재 지면"이 중심이야.
- 위 얇은 머리글: 왼쪽 "AIONIT / AI Agent 개발 · 초급 / 2장", 오른쪽 진도 "64%" + 3px 진도 막대, 다크 모드 전환, Q&A 열기.
- 3단: 왼쪽 목차(240) · 가운데 본문(최대 720) · 오른쪽 여백 메모(240).
- 목차: "2장 LLM API와 HTTP" 아래 2.1 LLM API와 HTTP / 2.2 요청 만들기(현재 — 왼쪽 2px 강조색 선 + 굵게) / 2.3 응답 읽기 / 2.4 messages와 role / 실습 첫 API 요청 / 2.5 토큰과 사용료. 끝난 절은 초록 ✓. 번호는 Mono.
- 본문 맨 위: 그 장의 강의 영상(16:9).
- 본문: 절 제목 "2.2 요청 만들기", 문단 2개 (17px, 줄 간격 1.8). 예: "LLM API 요청은 엔드포인트, 헤더, 본문 세 부분으로 이루어진다. 헤더에는 API 키를 넣어 누가 보낸 요청인지 알리고, 본문에는 모델 이름과 메시지를 JSON으로 담는다."
- 그림 1개: 흰 지면 위 도식 자리 + 아래 "그림 2-1. LLM API 호출의 층".
- 코드 블록: 라이트 화면에서도 어두운 바탕(#121A26). 머리줄에 "python · llm_client.py", 줄 번호, [복사] 버튼. 파이썬 requests.post 예제 5줄.
- 실습 구역: "실습 1 · 첫 API 요청" 제목, 실습 파일 내려받기 링크, 그 아래 "스스로 확인 3 / 4" 체크리스트 4줄 (.env 에 API 키를 넣었다 / 상태 코드 200 을 받았다 / 응답에서 답 내용을 꺼내 출력했다 / 출력한 요청에 키 앞부분만 보인다).
- 여백 메모 2개: "참고"(위 2px 강조색 선) — API 키는 .env 에서 읽고 Git에 올리지 않는다. "실무"(위 1px 진한 선) — 제공사마다 엔드포인트와 모델 이름이 다르니 설정 파일 한 곳에 모은다.
- 본문 끝: [← 2.1 이전] [다음 2.3 응답 읽기 →].
```

### A-03 로그인 · A-01 회원가입 (데스크톱)

### 마이페이지 — L-01 내 강의실 · M-01 내 정보 (데스크톱)

```
마이페이지를 만들어 줘.
- 왼쪽 메뉴: 내 강의 · 구독 · 결제 내역 · 계정 설정.
- "이어서 공부하기": 마지막에 보던 강의 1개 크게 — 강의 이름, "2.2 요청 만들기", 진도 막대 64%, 채운 버튼 [이어서 보기].
- 내 강의 목록: 줄 목록 — 강의 이름 | 진도(막대 + %) | 실습 체크(3/12) | 마지막 학습일 | 상태(● 이용 중 / ● 기간 만료).
- 구독 상태 한 줄: "● 이용 중 · 연간 구독 · 다음 결제 [날짜]" + 글 링크 "구독 관리 →".
```
