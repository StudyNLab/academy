## 1. 방향

**차분한 전문성 · 책 같은 화면.** 오래 읽는 교재가 중심인 서비스라서, 화려함보다 읽기 편함과 신뢰감을 우선한다.

| 한다 | 하지 않는다 |
|---|---|
| 구역은 **1px 선과 여백**으로 나눈다 | 모든 것을 테두리 상자 · 카드에 넣기 |
| 글자 크기 대비를 크게 (제목 64 vs 본문 17) | 비슷한 크기의 글자만 늘어놓기 |
| 강조 색(Signal)은 번호 · 현재 위치에만 조금 | 색 배지(칩)를 여기저기 붙이기 |
| 상태는 **점 + 글**로 (● 이용 중) | 색만으로 상태 구분하기 |
| 실제 교재 그림 · 실제 코드 · 실제 화면 | 의미 없는 장식 그림, 그라데이션 배경 |
| 번호 · 라벨은 고정폭 글꼴(Mono) 대문자 | 이모지 아이콘 |
| 한 화면에 채운(primary) 버튼은 하나 | 채운 버튼 여러 개 |

### 3.1 워드마크 "AIonIT"

- 글자만, 심볼 없음. **Manrope 800** 으로 `AI` 와 `IT`, 그 사이에 **Manrope 700 · 0.82em · 빨강(`--logo-on`)** 으로 소문자 `on`. 자간 −4.5%, 기준선 맞춤. 이름이 곧 문장 — "IT 의 바탕 위에 AI 를 켠다".
- 색: 종이 · 흰 바탕에는 Ink + `#D62828`. 남색 바탕에는 Paper + `#FF6B5E`. 다크 모드에는 Ink(밝은) + `#FF5A4E`. 단색(인쇄 · 팩스)이 필요하면 `on` 도 같은 색.
  - 이 빨강은 **로고의 `on` 에만** 쓴다 (토큰 `--logo-on`). 링크 · 강조 · 그림의 포인트는 그대로 Signal(벽돌색).
  - 2026-11-05: 가늘고 작은 Signal 색 `on`(300 · 0.78em) 에서 굵은 빨강으로 바꿨다. 머리글 크기에서 `on` 이 흐려 보여서.
- 한 벌
  - **가로**: 머리글 · 문서 머리 · 이메일 서명. 뒤에 가는 세로선(1px, 35%) 과 `아이오닛`(Plex 500 · 0.3em · 자간 +24%) 을 붙일 수 있다 (`<Wordmark korean />`). 머리글에서는 뗀다.
  - **세로**: 첫 화면 · 영상 끝 화면 · 명함. `아이오닛` 을 아래에 (`WordmarkStacked`).
  - **정사각**: 앱 아이콘 · 프로필 · 파비콘. Navy 바탕에 `AI / on / IT` 세 줄 (`SquareMark`). **24px 아래에서는 `on` 을 빼고 `AI` 만.** 파일은 `apps/web/scripts/make-icons.mjs` 로 만든다 (`icon.png` 64 · `apple-icon.png` 180 · `public/icon-512.png`).
- 여백: 사방에 대문자 I 높이만큼. 최소 크기: 가로 한 벌은 높이 18px(화면) · 5mm(인쇄), 그보다 작으면 정사각 `AI`.
- 하지 않는 것: 늘리거나 기울이지 않기 · `on` 을 대문자로 바꾸지 않기 · 심볼 · 그림자 · 테두리 덧붙이지 않기 · 서체 바꾸지 않기 · 다른 색 입히지 않기.
- 전원 기호(O) 워드마크는 **폐기** (2026-11-04). 되살리지 않는다.
- **임시 브랜드다.** 실오픈 전에 전문 디자이너에게 로고 · 브랜드를 맡긴다 (의뢰서 [디자인/디자이너_의뢰_브리프.md](디자인/디자이너_의뢰_브리프.md), 반영 순서 [디자인/도입계획.md](디자인/도입계획.md)). 그때는 `Wordmark.tsx` 와 이 장만 바꾼다.

### 3.2 그림 (일러스트)

**교육 내용을 그린 그림** 으로 채운다. 사진은 첫 화면 배경 한 곳에만 (3.4). 코드는 `packages/ui/src/Illustration.tsx`.

- 세 분야 그림 (120×96, 홈에서는 132×106): **연한 바탕(`--illust-bg`) + 남색 선(`--illust-ink`, 2px) + Signal 하나**. 칸 · 노드 안쪽 면은 `--surface`. 토큰이라 다크 모드에서 그대로 쓴다. 어두운 남색 면은 너무 무거워서 쓰지 않는다.
  - 인프라 = 서버 랙, 표시등 셋이 차례로 깜빡인다. 보안 = **로그가 든 방패**, 줄 하나가 Signal 이고 검사선이 오르내린다. AI = **노드 망**, 노드 사이로 신호가 흐르고 출력 노드에서 퍼진다.
  - 기준은 "설명 없이 0.5초 안에 분야가 읽히는가" — 과정 내용에서 출발한 그림(로그 줄 · 루프)은 아는 사람에게만 읽혀서 버렸다.
- 첫 화면: 그림 대신 **실습 서버 터미널** (3.3). 추상적인 층 그림(`LayersIllustration`)은 뜻이 읽히지 않아서 2026-11-04 에 뺐다.
- 강의 표지 (96×96): Navy 바탕(라이트 · 다크 공통) 에 Mono 번호 + 분야 무늬 (`CourseCover`). 목록 · 상세 · 내 강의실에서 같은 표지를 쓴다.
- 교재 그림(PNG) 은 홈에서도 **밝은 지면 위에** 둔다 (2.1 과 같은 이유).
- 피할 것: 로봇 · 회로 · 뇌 · 전구 · 반짝임(✦) · 그라데이션 · 이모지. 장식 그림은 `aria-hidden`, 뜻이 있는 그림은 `role="img"` + `aria-label`.

### 3.3 움직임

코드는 `packages/ui/src/motion.css` (class 이름은 모두 `aio-`). 캔버스 "AIONIT 디자인" › **P-01 홈 · 연출 시안** 이 원본.

- 원칙: **첫 화면 한 번 + 그림 안의 작은 반복 + 마우스 반응.** 움직임은 이 서비스의 내용(서버 · 로그 · 실습)을 보여 줄 때만 쓴다. 빛 번짐 · 네온 · 반짝임 · 화면 전환 애니메이션은 쓰지 않는다.
- 첫 화면 (v0.3, v0.4 에서 시안 AIONIT-Service 의 밝은 첫 화면으로 바뀌어 지움)
  - 제목 · 소개 · 버튼이 차례로 떠오른다 (`aio-up`, 0.7초, 0.1~1초 간격). 배경 사진은 18초 동안 아주 천천히 당겨진다 (`aio-zoom`).
  - **실습 서버 터미널**이 14초마다 돈다: 탭 `01 인프라` → `02 보안` → `03 AI` 가 차례로 켜지고, 서버 접속 · nginx 확인 → 로그에서 반복 로그인 1,284건 찾기 → 에이전트가 요약 · 차단 제안. "IT 의 바탕(인프라 · 보안) 위에 AI 를 켠다" 를 실습 장면으로 보여 준다.
- 홈 학습 화면 모형: 실습 코드가 한 줄씩 쳐지고 → 실행 결과 `200` → 평가 기준 한 줄이 체크된다 (10초 반복).
- 분야 그림: 3.2 의 작은 반복. 마우스를 올리면 그림이 4px 떠오른다.
- 마우스 반응: 글 링크의 → 가 4px 밀린다. 강의 줄은 표지 무늬가 커지고 제목이 링크 색으로. 남색 바탕 위 밝은 버튼은 Signal 밝은 색(`#F0A88C`)으로.
- 구역 들어오기: 화면에 들어올 때 살짝 떠오른다 (`aio-reveal`, CSS 스크롤 타임라인). 지원하지 않는 브라우저에서는 그냥 보인다.
- **움직임 줄이기 설정**이면 전부 멈추고 완성된 모습(마지막 줄까지 쳐진 터미널, 체크된 평가 기준)만 보인다.

## 4. 부품 규칙

| 부품 | 규칙 |
|---|---|
| 버튼 | 높이 52(L) · 44(M) · 36(S). 채운 버튼 = 주 행동 하나. 나머지는 외곽선 또는 글 링크(밑줄 + →). 위험 행동은 Danger 색 |
| 입력 | 높이 44, 라벨은 위에, 오류는 테두리 + 아래 글(색만으로 알리지 않음) |
| 상태 표시 | 7px 사각 점 + 글. 이용 중(Done) · 해지 예약(Warn) · 결제 실패(Danger) · 끝남(회색) |
| 강의 속성 | 배지 대신 글: "구독 포함 / **프리미엄** / 무료 공개(Signal)" |
| 진도 | 3px 막대(`--link`) + 숫자 |
| 강의 목록 | 카드 그리드 대신 **줄 목록**: 번호 · 강의 · 분야 · 구성 · 수강 방법 |
| 목차 | Mono 번호 + 제목. 현재 위치는 왼쪽 2px Signal 선 + 굵게. 완료는 ✓(Done) |
| 코드 | 어두운 바탕(라이트에서도). 머리줄: 꼬리표(▶ 실행 · 파일 · 줄 번호) + 복사. 줄 번호는 실제 파일 줄 |
| 여백 메모 | 참고(Signal) · 실무(Ink) · 주의(Warn). 데스크톱은 본문 옆 여백, 좁은 화면 · Q&A 패널이 열렸을 때는 본문 사이 |
| 영상 | 16:9, 바탕 `#1B2534`, 가운데 재생 버튼, 아래 3px 진행 막대(Signal). 아래 설명줄에 "무료 공개" 또는 "수강생 전용". 수강생 전용은 닉네임 워터마크 |
| 스스로 확인 | 위 굵은 선 + 제목 + `n / m`, 항목마다 가는 선. 체크 즉시 저장 |

## 6. 개발로 옮길 때

- 토큰은 CSS 변수(`:root` / `[data-theme="dark"]`)로 만들고, Tailwind 를 쓰면 이 변수를 테마로 연결한다.
- 다크 모드: 운영체제 설정을 따르되, 머리글 · 학습 화면의 버튼으로 직접 바꾼 값을 기억한다 (사이트 전체에 적용).
- 부품은 공통 컴포넌트 하나씩 (Button, Field, StatusDot, ProgressBar, CourseRow, Toc, CodeBlock, MarginNote, VideoPlayer, SelfCheck, DataTable, Toast, Dialog). 화면은 이 부품만 조합한다.
- 교재 본문(업로드 패키지의 `content.html`) 스타일은 `academy.css` 의 class 이름을 그대로 받아 이 토큰으로 다시 칠한다.
