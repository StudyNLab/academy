# 구글 · 카카오 로그인 앱 등록 안내 (운영자)

- 작성: 2026-11-04 (M1)
- 상태: **구글 완료** (2026-11-04, 프로젝트 `aionit-513621`, 클라이언트 `AIONIT web`, 테스트 사용자 studynlab@gmail.com). **카카오는 나중에** (운영자 결정: 전체 구성 먼저)
- 왜 운영자가 하나: 앱 등록은 운영자 본인 계정으로 로그인해 약관에 동의하는 일이라 대신할 수 없다.
- 등록이 끝나면 키 4개를 **노트북의 `.env` 파일에만** 넣고 알려 주면, 나머지(테스트 서버 반영 · 확인)는 Claude 가 한다. **키 값은 채팅에 붙여 넣지 않는다.**

## 0. 공통: 돌아올 주소 (Redirect URI)

| 환경 | 구글 | 카카오 |
|---|---|---|
| 개발 (노트북) | `http://localhost:3000/api/v1/auth/callback/google` | `http://localhost:3000/api/v1/auth/callback/kakao` |
| 테스트 서버 | `https://localhost:18443/api/v1/auth/callback/google` | `https://localhost:18443/api/v1/auth/callback/kakao` |

도메인이 생기면 `https://<도메인>/api/v1/auth/callback/google` · `…/kakao` 를 더한다.

## 1. 구글 (약 10분)

1. https://console.cloud.google.com 에 운영자 구글 계정으로 로그인
2. 위쪽 프로젝트 선택 ➔ **새 프로젝트** ➔ 이름 `AIONIT` ➔ 만들기 ➔ 그 프로젝트 선택
3. 왼쪽 메뉴 **Google 인증 플랫폼(Google Auth Platform)** ➔ **시작하기**
   - 앱 이름 `AIONIT`, 사용자 지원 이메일: 운영자 이메일
   - 대상(Audience): **외부(External)**
   - 연락처 이메일: 운영자 이메일 ➔ 동의 ➔ 만들기
4. **대상(Audience)** 화면 ➔ 게시 상태가 **테스트 중(Testing)** 인지 확인 ➔ **테스트 사용자 추가**에 로그인해 볼 구글 계정(운영자 계정 + 시험용 계정)을 넣는다
   - 테스트 중에는 여기 넣은 계정만 로그인된다. 실오픈 때 "앱 게시"로 바꾼다 (이메일 · 프로필만 쓰므로 구글 심사는 간단하다)
5. **데이터 액세스(Data access)** ➔ 범위 추가: `openid`, `.../auth/userinfo.email`, `.../auth/userinfo.profile` (기본 범위, 민감 범위 아님) ➔ 저장
6. **클라이언트(Clients)** ➔ **클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**, 이름 `AIONIT web`
   - 승인된 리디렉션 URI: 위 0번 표의 구글 주소 2개
   - 만들기 ➔ 나오는 **클라이언트 ID** 와 **클라이언트 보안 비밀번호(Client secret)** 를 아래 3번처럼 `.env` 에 넣는다

## 2. 카카오 (약 10분)

1. https://developers.kakao.com 에 운영자 카카오 계정으로 로그인 (처음이면 개발자 등록 동의)
2. **내 애플리케이션** ➔ **애플리케이션 추가하기**: 앱 이름 `AIONIT`, 회사명(개인이면 운영자 이름), 카테고리 `교육` ➔ 저장
3. **앱 키**(또는 플랫폼 키) 화면에서 **REST API 키**를 확인한다 ➔ 이것이 `KAKAO_CLIENT_ID`
4. **플랫폼 ➔ Web**(사이트 도메인): `http://localhost:3000`, `https://localhost:18443`
5. **카카오 로그인** ➔ 활성화 **ON** ➔ **Redirect URI** 에 위 0번 표의 카카오 주소 2개 등록
   - 새 콘솔에서는 Redirect URI · Client Secret 이 "REST API 키" 상세 화면 안에 있을 수 있다. 메뉴 이름이 달라도 같은 항목을 찾으면 된다
6. **동의항목** ➔ **닉네임(profile_nickname)**: "필수 동의", 동의 목적 "로그인 확인"
   - 이메일(account_email)은 비즈 앱이어야 받을 수 있다. 지금은 받지 않는다 (카카오 회원은 이메일 없이 가입되고, 메일 알림을 받지 못한다 — `docs/데이터모델.md` 3.1)
7. **보안 ➔ Client Secret** ➔ 코드 생성 ➔ 활성화 상태 **사용함** ➔ 이 코드가 `KAKAO_CLIENT_SECRET`

## 3. 키 넣기 (노트북)

메모장으로 `E:\온라인아카데미_개발_운영관리\.env` 를 열고, 맨 아래에 아래 네 줄을 넣어 값을 채운 뒤 저장한다 (따옴표 없이).

```text
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
KAKAO_CLIENT_ID=
KAKAO_CLIENT_SECRET=
```

그다음 Claude 에게 "키 넣었어" 라고만 말한다. Claude 가 값은 보지 않고(출력하지 않고) 테스트 서버 `.env` 로 옮기고, 가입 화면 · 로그인 화면에 버튼이 생기는지, 콜백이 맞게 설정됐는지 확인한다.

## 4. 운영자가 직접 확인할 것 (테스트 계정)

https://localhost:18443 (infra/README.md 의 터널) 에서:

| 확인 | 기대 결과 |
|---|---|
| 로그인 화면 ➔ 구글로 로그인 (가입 전 계정) | "아직 가입하지 않은 계정입니다" 안내, 회원이 만들어지지 않음 |
| 가입 화면 ➔ 닉네임 · 동의 체크 ➔ 구글로 가입하기 | 가입되고 로그인됨, 내 정보에 구글 "연결됨" |
| 이메일로 가입한 계정과 **같은 구글 이메일**로 로그인 | "같은 이메일로 가입한 계정이 이미 있습니다" (자동 연결 안 함, A-05) |
| 이메일 계정으로 로그인 ➔ 내 정보 ➔ 구글 · 카카오 연결하기 | 연결됨. 그 뒤로는 구글 · 카카오로 같은 계정에 들어옴 |
| 카카오로 가입 | 가입됨, 내 정보 이메일 칸 "등록된 이메일 없음 (카카오 로그인)" |
| 운영자 계정에 구글을 연결 ➔ 구글로 로그인 ➔ `/admin` | OTP 를 한 번 더 묻는다 |
