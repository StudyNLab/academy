**데이터**: `chapters`(published 버전), `video_slots`, `entitlements`, `chapter_progress`, `video_watch`, `self_checks`, `questions`

### 1.2 구성 요소

| 요소 | 내용 |
|---|---|
| 학습 머리글 | 내 강의실로 돌아가기, 과정 이름, 과정 진도 막대(%), Q&A 버튼(이 챕터의 미해결 질문 수), 다크 모드, 내 메뉴 |
| 목차 | 모든 챕터(접고 펴기). 지금 챕터는 펼쳐서 Section · 🎬 끼운 영상 · 실습을 보여준다. 지금 읽는 곳 ● 표시. 챕터 완료 ✓, 실습 체크 진행 `3/4`, 볼 수 없는 챕터 🔒 |
| 챕터 영상 | 맨 위. 없으면 생략. 유튜브(무료 공개) 또는 자체 서버 |
| 교재 본문 | 업로드 패키지의 `content.html`. 코드 복사 버튼, 그림 크게 보기, 접은 코드 |
| 끼운 영상 | 교재의 영상 자리. 제목 + 플레이어. 처음에는 썸네일만 보이고 누르면 불러온다 (페이지가 무거워지지 않게) |
| 스스로 확인 | 실습 Section 끝. 체크하면 바로 저장. 다 체크하면 목차의 실습에 ✓ |
| 챕터 끝 | 이 챕터 완료 조건 요약, 첨부 자료, 이전 · 다음 챕터 |

### 1.3 누가 무엇을 보나

| 상황 | 화면 |
|---|---|
| 수강권 있음 | 전부 |
| 수강권 없음 + 무료 미리보기 챕터 | 미리보기로 정한 Section 만 보이고, 나머지 Section 은 제목만 + "수강하면 볼 수 있습니다" [구매하기] [구독하기] |
| 수강권 없음 + 미리보기 아닌 챕터 | L-05 로 보낸다 |
| 유튜브 영상 | **누구나 재생** (미리보기 화면에서도) |
| 자체 서버 영상 + 수강권 없음 | 🔒 카드 "수강생 전용 영상입니다" |
| 수강권 만료 | L-05 (만료 안내 + 연장권 · 구독) |
| 로그인 안 함 | 미리보기만. 진도 · 체크는 저장되지 않고 "로그인하면 진도가 저장됩니다" 안내 |

### 1.4 진도 · 이어서 보기

| 항목 | 규칙 |
|---|---|
| 읽은 위치 | 스크롤이 멈추고 5초 뒤 저장. 화면을 떠날 때 마지막으로 한 번 더 저장 |
| 다시 들어왔을 때 | 마지막 Section 이 첫 Section 이 아니면 위에 "마지막으로 읽은 곳: 3. 응답 읽기 [이동]" (자동으로 튀지 않는다) |
| 교재 완료 | 마지막 Section 까지 내려가고 그 챕터에 머문 시간이 최소 기준(글 분량 기준) 이상 |
| 영상 완료 | 90% 이상 재생. 다시 열면 멈춘 곳부터 |
| 챕터 완료 | 교재 완료 + 모든 영상 완료 + 모든 체크. 목차에 ✓, 과정 진도 막대 갱신 |
| 학습 시간 | 화면이 보이고 활동이 있는 동안 30초마다 신호 (`learning_heartbeats`). 2분 활동 없으면 멈춤 |
| 연결 끊김 | 위에 "연결이 끊겼습니다. 진도는 다시 연결되면 저장됩니다" 띠. 체크 · 위치는 브라우저에 모아 뒀다가 보낸다 |

### 1.5 콘텐츠 보호

- 자체 서버 영상: 닉네임 + 회원 번호 일부를 반투명 워터마크로, 위치를 천천히 바꾼다. 영상 위 오른쪽 클릭 막기.
- 교재: 배경에 아주 옅은 닉네임 워터마크.
- **글 선택 · 복사는 막지 않는다.** 코드를 복사해서 실습하는 강의라 막으면 불편하기만 하고, 마음먹은 사람은 어차피 우회한다. 유출 추적은 워터마크로 한다. (이전 제안의 "복사 제한"은 이 결정으로 바꾼다)

### 2.3 구매 카드의 상태

| 내 상태 | 카드 |

| 로그인 안 함 / 수강권 없음 | 가격, [구매하기], 구독 안내 |

| 구독자 + 프리미엄 강의 | 구독자 할인가 강조 [할인가로 구매하기] |
| 이미 단건으로 보유 | "수강 중 · 2027.11.03 까지" [학습하기] |
| 수강권 만료 | "수강 기간이 끝났습니다" [연장권 17,700원] [다시 구매] |
| 판매 중지 | "지금은 판매하지 않는 강의입니다" (보유자는 계속 학습) |

## 4. M-03 구독 관리

**원칙**: 해지는 가입만큼 쉬워야 한다. 해지를 막는 단계(설문 강요, 할인 제안 반복, 상담 연결)를 두지 않는다.

```text
┌ 구독 관리 ────────────────────────────────────────┐
│ 연간 구독   [이용 중]                                 │
│ 다음 결제   2027.11.03 · 199,000원                    │
│ 결제 수단   신한카드 •••• 1234        [결제 수단 변경]   │
│ ──────────────────────────────────────────────── │
│ [구독 해지]                                          │
│ 결제가 이미 된 기간을 바로 끝내고 환불받으려면 ▸           │
└──────────────────────────────────────────────────┘
```

**해지 흐름** (클릭 2번)

```text
[구독 해지] ➔ 확인 창
   "2027.11.03 까지는 지금처럼 이용할 수 있고, 그 뒤에는 자동결제가 되지 않습니다.
    진도 기록은 지워지지 않습니다. 사유를 알려 주시면 개선에 쓰겠습니다 (선택)."
   [해지 예약]  [계속 이용]
➔ 결과: "해지가 예약되었습니다 · 2027.11.03 까지 이용" + 메일
```

| 상태 | 화면 |
|---|---|
| 이용 중 | 위 화면 |
| 해지 예약됨 | "2027.11.03 까지 이용 후 끝납니다" [해지 취소] |
| 결제 실패 | 위에 빨간 띠 "자동결제에 실패했습니다. 결제 수단을 바꿔 주세요. 2026.11.10 까지 이용할 수 있습니다" [결제 수단 변경] |
| 끝남 | "구독이 끝났습니다" [다시 구독하기]. 진도는 남아 있음 |

**즉시 해지 · 환불** (작은 링크 ▸): 5장의 환불 요청 화면과 같은 방식. 예상 환불액을 먼저 보여준다.

## 5. M-04 결제 내역 · 환불 요청


```text

│ 결제일 2026.11.03 · 결제 금액 44,250원                │

│ 진도율 38%                                          │
```

- 영수증: 카드 영수증은 토스 영수증 링크. 현금영수증 · 세금계산서는 2단계.
