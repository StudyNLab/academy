## 테스트로 찾은 문제 (고침)

- 챕터 비교값에 버전마다 다른 그림 주소가 들어가 모든 챕터가 "변경"으로 보임 ➔ 그림 주소를 패키지 경로로 되돌려 계산
- 압축 폭탄 · 경로 탈출 시 zip 라이브러리 오류가 보고서 코드로 바뀌지 않아 처리 자체가 멈춤 ➔ 코드로 바꿈
- 백업 스크립트: 첫 실행에 `changed` 폴더가 없으면 정리 명령이 실패해 스크립트가 멈춤 ➔ 미리 만든다
- 같은 PC 에서 가입 시험을 반복하면 IP 횟수 제한(10분 5회)에 걸림 ➔ 화면 흐름 테스트가 개발 DB 의 카운터를 비우고 시작 (제한은 그대로 동작함을 확인한 셈)

## 교재 세션에 전할 것 (`--export` 만들 때)

- 실제 교재 HTML 에 `실습영상/ch01_lab01_v020.html` 같은 **로컬 파일 링크 10개**가 있다. 패키지에서는 허용 목록 밖이라 지워진다 ➔ 규격 3.4 의 영상 자리(`div.video-slot`, key `ch01_lab01`)로 바꾸면 운영자가 영상을 연결할 수 있다.
- `labs[].self_check` 가 비어 있다 (규격 2.2 "결정 필요"). 정해지면 학습 화면(M3)의 스스로 확인 체크가 채워진다.
- 그림은 지금 base64 로 박혀 있다 ➔ `--export` 는 `images/` 파일 + `width`·`height` 로 (규격 3.2). 임시 변환기로는 문제없이 통과했다.
