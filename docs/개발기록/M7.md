## 정한 것 · 바뀐 결정

| 무엇 | 정한 것 | 이유 |
|---|---|---|
| 질문 쓰기 | 수강권이 있는 수강생만. 운영자 · 그 과정 강사는 답 · 고정만 | 완료 기준 "수강생만". 강사 · 운영자가 질문을 쓸 일이 없다 |
| 답변 쓰기 | 그 강의를 볼 수 있는 사람 모두 (수강생끼리 포함). 비밀글에는 질문자 · 강사 · 운영자만 | 사이트구조 L-06 "수강생끼리 답변" |
| 숨긴 글 | 다른 수강생의 목록에서 빠지고, 작성자 · 강사 · 운영자에게만 사유와 함께 보인다. 지우지는 않는다 (다시 보이기 가능) | AD-17 "숨김 · 삭제(사유)" 중 되돌릴 수 있는 숨김만. 글을 아주 지우는 일은 작성자 몫 |
| 작성자가 지우기 | 제목 · 내용을 비우고 목록에서 뺀다. 달린 답변 행은 남는다 | API 키 · 개인정보를 잘못 올렸을 때 바로 없앨 수 있게 |
| API 키 경고 | 서버가 저장 전에 찾아 409 로 알리고, 확인하면 그대로 저장 | 화면상세기획 1.6 "저장은 막지 않고 한 번 더 확인". 화면을 거치지 않는 요청에도 같은 규칙 |
| 같은 질문 찾기 | 제목 · 내용에서 글자 그대로 찾기(`%` `_` 도 글자). 다른 사람의 비밀글은 찾지 않는다 | 비밀글 내용이 검색 결과로 새지 않게 |
| 답변 메일 | 사이트 알림은 답변마다, 메일은 그 질문의 알림을 읽지 않은 동안 한 번만 | 답변이 여러 개 달려도 메일이 쏟아지지 않게 |
| 알림 설정 | Q&A 답변 · 만료 알림 메일만 끌 수 있다. 사이트 알림은 끄지 않는다 | 데이터모델 `notification_prefs`. 결제 · 환불 · 구독 · 문의 답변은 꼭 알아야 하는 일 |
| 1:1 문의 보관 | 문의 · 글은 고치거나 지울 수 없고 마지막 글부터 3년 뒤 정리 작업이 지운다. 탈퇴해도 남는다 | 전자상거래법 소비자 불만 · 분쟁 기록 3년 (데이터모델 4장) |

## 테스트로 찾은 문제 (고침)

- 학습 화면에서 패널을 열면 1024px 폭에서 본문이 330px 로 줄어듦 ➔ 1280px 아래에서는 패널을 연 동안 목차를 접는다
- 좁은 화면 머리글에 🔔 를 더하자 한 줄에 들어가지 않음 ➔ 좁은 화면은 회원 메뉴 안에 "알림 n" + 닉네임 옆 점
- 개발 PC 에 다른 세션의 worker 가 여럿 떠 있고 하나는 파일을 다시 읽지 않아(옛 코드) 새 문안의 메일을 **빈 제목 · 빈 내용**으로 보냄 ➔ worker 가 모르는 문안이면 보내지 않고 다시 시도하게 고침. 화면 흐름 테스트는 메일 기록(`email_logs`)으로 확인하고, 실제 문안은 테스트 서버에서 확인
