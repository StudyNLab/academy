## 테스트로 찾은 문제 (고침)

- 시행 중인 강사 이용약관을 고를 때 날짜를 SQL 글자로 넣어 DB 드라이버가 거부 ➔ 비교 함수로
- 테스트 DB 를 비울 때 `users` 를 비우면 기본 배분 정책까지 함께 비워짐(작성자 FK) ➔ 정책의 작성자는 FK 없이 두고, 테스트는 기본 정책만 남긴다
- 관리자 메뉴에 "검수 대기" 가 생겨 M2 화면 흐름 테스트의 "검수 대기" 글자가 둘로 잡힘 ➔ 본문 안의 상태 표시만 보게 고침
- 개발 PC 에 다른 창(main 코드)의 worker 가 4개 떠 있어 새 문안 메일이 그 worker 들에서 "모르는 문안"으로 다시 시도됨 (M7 에서 막은 대로 빈 메일은 안 나감) ➔ 화면 흐름 테스트는 보낸 메일 대신 **메일 대기열**(`pgboss.job`)에 사유가 들어갔는지 본다. 문안은 단위 테스트로 확인
