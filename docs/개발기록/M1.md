## 바뀐 결정

| 원래 | 바뀜 | 이유 |
|---|---|---|
| `users.email` 비어 있을 수 있음 | 비워 둘 수 없음. 카카오(이메일 없음) · 탈퇴 회원은 `…@….invalid` 자리표시 | Better Auth 가 이메일을 필수로 요구. `.invalid` 는 메일을 보내지 않는다 |
| `users.name`(이름) | 받지 않음. 라이브러리의 `name` 칸을 닉네임으로 씀. 구글 · 카카오의 이름 · 사진도 저장 안 함 | 최소 수집. 지금 실명이 필요한 곳이 없다 (정산 정보는 M9 의 강사 테이블) |
| 해시: scrypt 또는 argon2id | argon2id (`@node-rs/argon2`) | 데이터모델 문서대로. OWASP 권장값 |
| 기록 테이블은 DB 권한으로 덧붙이기만 | DB 트리거로 막음, 권한 분리는 M10 | 지금은 앱 · 마이그레이션이 같은 DB 계정. 트리거는 소유자 계정에도 걸린다 |
| 로그인 기록에 이메일 | 이메일 대신 HMAC | 계정별 실패 횟수는 셀 수 있고, 탈퇴 뒤 이메일이 기록에 남지 않는다 |
| 인증 API `/api/auth` | `/api/v1/auth` | 쓰기는 `/api/v1` 로 모은다는 규칙(기술설계 2.1) |
| 계정 연결은 같은 이메일만 | 로그인한 상태의 직접 연결은 이메일이 달라도 허용 (자동 연결은 계속 금지) | 카카오는 이메일이 없다. 로그인 = 본인 확인 |
| 관리자 진입 = 역할 + 2단계 인증 켜짐 | + **그 세션에서 OTP 통과** (`sessions.mfa_verified_at`) | 라이브러리의 2단계 인증은 이메일 로그인에만 걸린다. 구글 · 카카오로 들어온 세션이 OTP 를 건너뛰지 않게 |
| (없음) | 테스트 서버에도 Mailpit | 메일 발송 서비스가 정해지기 전 테스트 서버의 인증 메일 확인용. 정해지면 `SMTP_URL` 만 바꾼다 |
| Playwright 브라우저 내려받기 | 이 PC 의 Chrome(`channel: chrome`) | 외부 다운로드 없이 |

## 테스트로 찾은 문제 (고침)

- 약관 초안 시행 시각을 UTC 자정으로 넣어 한국 시간 새벽에는 "시행 전" ➔ KST 자정으로
- Better Auth 는 테스트 환경에서 Origin 확인을 끈다 ➔ 설정에서 항상 켬 (CSRF 테스트가 잡음)
- 우리 로그인 기록 훅이 2단계 인증 플러그인보다 먼저 돌아 OTP 대기를 "성공"으로 적음 ➔ 고침
- 로그인 중 OTP 재확인에는 라이브러리의 시도 제한이 없다 ➔ 15분 5회 잠금 추가
- 운영자 세션이 "쓰면 연장" 규칙으로 30일까지 늘어남 ➔ 연장할 때도 12시간에서 자름
- 관리자 회원 목록의 역할 칸이 비어 보임 (하위 쿼리의 열 이름) ➔ 고침
