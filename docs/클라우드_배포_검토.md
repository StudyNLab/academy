## 1. 지금 구성과 베타 규모

| 구성 | 지금 (테스트 서버) | 운영 서버 한 대 (`infra/cloud/compose.yaml`) |

| PostgreSQL · Garage | data VM, 내부망 172.30.0.20 | 같은 서버, 컨테이너 망 안에서만 (밖에 안 연다). DB 소유자 비밀번호는 `.env.data` 에만 |

**베타 규모 (추정)**: 교육생 수십 명, 영상은 대부분 유튜브(우리 서버를 거치지 않음). 우리 서버가 내보내는 것은 화면 · 교재 · 직접 올린 소수 영상 ➔ **월 수 GB ~ 수십 GB**. 저장은 강의 · 첨부 · 소수 영상 원본과 변환 결과로 **수 GB ~ 20GB**. 지금 백업 전체가 38.9MB (2026-11-05).

## 2. 메모리 하한 (서버 크기)

함께 도는 것: web · worker · PostgreSQL · Garage · Caddy · 감시 + OS · Docker. 영상 변환(ffmpeg)은 드물다.

| 구성 | 평소 (추정) | 근거 |
|---|---|---|
| OS · Docker | 300 ~ 400MB | Ubuntu 서버 + dockerd · containerd |
| web (Next.js standalone) | 200 ~ 350MB | Node 서버 하나, 화면 렌더링 |
| worker (Node + 작업 대기열) | 150 ~ 250MB | 평소. **영상 변환 중에는 ffmpeg 가 0.5 ~ 1GB 더** (1080p · 720p · 360p 를 한 번에) |
| PostgreSQL | 200 ~ 350MB | 기본 설정(shared_buffers 128MB) + 접속 10개 |
| Garage | 50 ~ 150MB | 파일 수가 적다 |
| Caddy · Gatus | 60 ~ 100MB | |
| **합계** | **평소 약 1.0 ~ 1.6GB**, 변환 중 2 ~ 2.6GB | |

- 위 값은 **추정**이다. 테스트 서버에서 `docker stats` · `free` 로 실제 값을 재 보는 것은 총괄 창 허락을 기다리는 중이며, 재면 이 표를 실제 값으로 고친다.
- 결론: **2GB + 스왑 2GB** 로 평소는 여유가 있고, 드문 영상 변환은 worker 상한(1GB, 넘치면 스왑까지) 안에서 느리게 끝난다. 배포 때 마이그레이션 컨테이너가 잠깐 하나 더 뜨는 것(약 200MB)도 들어간다.
- 1GB 서버는 하한 밑이라 쓰지 않는다. 4GB 는 넉넉하지만 값이 두 배다 ➔ **2GB 로 시작해 실측으로 판단**. 키우는 법: 스냅샷 ➔ 4GB 새 서버 ➔ 고정 IP 옮기기 (`infra/cloud/README.md` 끝).
- 빌드는 서버에서 하지 않는다 (지금처럼 사무실 개발 VM). 그래서 작은 서버로 된다.

**싸도 추천하지 않는 이유**

- **오라클 무료**: ① 무료 계정은 7일 동안 CPU · 네트워크 · 메모리가 20% 밑이면 서버를 회수할 수 있다 [13]. 교육생 수십 명 규모는 거의 늘 그 밑이다. ② 2026-06 에 무료 한도를 공지 없이 절반으로 줄였다 [14]. 또 바뀔 수 있다. ③ 춘천은 Arm 서버 자리가 없어 못 만든다는 보고가 있다 (일화). ④ Arm 서버라 이미지를 Arm 으로도 빌드해야 한다 (영상 변환용 ffmpeg 이미지 포함, 작업이 늘어남).
- **사무실 서버 + Cloudflare Tunnel**: ① 서비스 전체가 사무실 PC 한 대(호스트 Windows 10 21H2 — 지원 끝남, 실습 랩과 같이 씀)와 사무실 회선 · 전원에 달린다. ② 무료 요금제에서 영상 · 큰 파일을 내보내는 것은 약관(2026-09-28 수정본)이 막는다 [16]. 영상이 적어도 직접 올린 영상은 이 길로 나간다. ③ 무료 요금제에서 한국 접속이 해외 거점으로 돈다는 보고가 있다 (일화) [17].
- **크레딧만 보고 고르지 않는다**: 네이버 10만 원 크레딧은 3개월이면 끝나고, 그다음은 매달 약 7.6만 원이다. Lightsail 은 크레딧 뒤에도 약 1.9만 원.

## 4. 추천: AWS Lightsail 서울, 2GB 서버 한 대

**왜 (세 줄)**

1. **가장 싼데 믿을 수 있다**: $12 에 고정 IP · 60GB 디스크 · 전송 3TB 가 들어 있다 [1][3]. 회수 · 약관 위험이 없고, 서울 리전이라 국내 접속이 빠르다.
2. **지금 만든 것을 그대로 쓴다**: compose · Caddy · Garage · 백업 · 감시 · 배포 스크립트를 한 서버용으로 맞춰 두었다 (이 PR). 사무실 테스트 서버는 시험 서버로 남는다.
3. **바꾸기 쉽다**: 메모리가 모자라면 스냅샷으로 4GB 로, 직접 올린 영상이 늘어도 전송 포함분(3 ~ 4TB) 안이고, 오픈 뒤 비용을 보고 다시 정할 때도 compose 그대로 다른 곳으로 옮길 수 있다.

**구성**

| 항목 | 내용 |
|---|---|
| 서버 | Lightsail 서울 Ubuntu 24.04, 2GB · 2vCPU · 60GB, 고정 IP, 스왑 2GB |
| 방화벽 | 80 · 443 모두, **22(SSH)는 사무실 공인 IP 만**. 관리자 화면은 Caddy 에서 사무실 IP 만 (`ADMIN_ALLOW_IPS`) |
| 메일 | SES 서울 SMTP, 1,000통당 $0.10 [4]. 베타 메일 수백 통이면 1달러 미만. 도메인에 SPF · DKIM · DMARC |
| 백업 | 매일 03:30 서버 디스크 ➔ 04:10 사무실 테스트 서버가 읽기 전용 키로 받아 옴 ➔ G: ➔ 04:30 F: (지금 흐름). Lightsail 자동 스냅샷(매일, 7개) |
| 감시 | 서버 안 Gatus (도메인 · 인증서 만료 포함) + 사무실 테스트 서버 Gatus 가 바깥에서 한 번 더 |
| 배포 | `deploy.sh --cloud`. 빌드는 사무실 개발 VM, 서버에는 바뀐 층만 |

**알아 둘 점**

- 달러 · 해외 카드 결제. 원화 세금계산서 처리는 확인 못함 (운영자 확인).
- **가입하고 바로 유료 플랜으로 바꾼다**: 무료 플랜은 6개월이 지나거나 크레딧을 다 쓰면 계정이 닫히고, 쓸 수 있는 서비스가 제한된다 [4][5]. 유료로 바꿔도 남은 크레딧은 그대로 청구에 쓰인다 [5]. 크레딧 유효 기간은 안내마다 6개월 · 12개월로 달라 확인 못함.
- Lightsail CPU 는 버스트형이다 (추정). 영상 변환은 느려질 수 있지만 드물다.
- 해외 회사의 서울 리전이라 개인정보처리방침에 처리위탁(AWS · 서버 보관, 서울) 고지가 필요하고, 국외 이전 칸까지 적을지는 법률 검토 때 함께 묻는다 (5장).

## 5. 개인정보 · 결제 · 메일 (요약)

- **개인정보**: 국외 이전은 개인정보보호법 제28조의8. 계약 이행에 필요한 처리위탁 · 보관이면 처리방침에 항목 · 국가 · 시기 · 방법 · 받는 자 · 목적 · 보유 기간 · 거부 방법을 공개하면 된다 [18]. 해외 회사 서울 리전에 대한 개인정보보호위원회의 명시적 판단은 찾지 못했다. 통상 처리위탁 고지로 보되, 해외 원격 접근이 있으면 국외 이전으로 볼 여지가 있다 (추정 [19]). 처리방침 초안 `docs/정책초안/개인정보처리방침.md` 4 · 5장은 이미 [검토] 표시가 있다. 메일을 SES **서울**로 보내면 메일 주소도 서울 리전에서 처리된다.
- **토스 결제**: 서버 위치 · 고정 IP 를 요구하지 않는다. 웹훅 주소만 밖에서 열리면 된다 [20]. 베타는 결제 없음.
- **CSAP**: 공공기관에 공급하는 클라우드용 인증이라 민간 교육 사이트에는 필요 없다 (추정 [21]).
