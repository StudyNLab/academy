- 작성: 2026-11-07 · 가격 · 정책은 이날 웹에서 확인 (출처는 맨 아래 10장, 표의 번호 [n])
- 목적: 지인 5 ~ 10명 결제 없는 베타를 **어느 클라우드에, 어떤 방식으로** 올릴지 정한다. 그대로 실오픈(실결제 · 아무나 가입)까지 갈 수 있어야 한다.

## 1. 지금 구성 (저장소에서 확인)

| 구성 | 어디 | 옮길 때 걸리는 점 |
|---|---|---|
| Caddy (HTTPS · 보안 헤더 · `/media/*` 권한 확인 뒤 영상 내줌) | app VM | 사이트 주소 `localhost` + `tls internal` ➔ 도메인 + Let's Encrypt. 관리자 IP 제한 주석 풀기 (`infra/app-vm/Caddyfile`) |
| web (Next.js) · worker (영상 변환 ffmpeg · 메일 · 정산 · 자동결제) | app VM | 이미지 그대로. `.env` 의 주소 값만 바뀜 |
| Mailpit (메일 모아 두기) | app VM | 지운다. `SMTP_URL` · `MAIL_FROM` 을 발송 서비스로 |
| Gatus 감시 | app VM (`~/aionit-monitor`) | 그대로. 단 같은 서버가 통째로 죽으면 알림도 못 보냄 ➔ 사무실 테스트 서버에 바깥 감시 하나 더 (7장) |
| PostgreSQL · Garage(S3 호환, 버킷 `aionit` · `aionit-media`) | data VM, 내부망 `172.30.0.20` 에만 열림 | 클라우드 사설망 주소로. compose · Caddyfile · 감시 설정의 `172.30.0.x` 를 바꾼다 |
| 백업 (매일 03:30 DB · 파일 · 설정 암호화) | data VM ➔ 호스트 `G:` 공유 폴더 ➔ NAS `F:` | 공유 폴더가 없어진다 ➔ 클라우드 디스크에 쌓고 **사무실 호스트가 매일 받아 감**(G: · F: 흐름은 그대로) + 클라우드 스냅샷 |
| 배포 `infra/scripts/deploy.sh` | 노트북 ➔ 호스트 경유 SSH(ProxyJump) ➔ 개발 VM 빌드 ➔ **사내 브리지 망**으로 app VM 이 받아 감 | 클라우드 VM 은 사내 브리지 망에 닿지 않는다 ➔ 개발 VM 이 클라우드 app VM 으로 **SSH 역방향 터널**을 열어 같은 보관소에서 바뀐 층만 받게 바꾼다. 빌드는 계속 사무실 개발 VM 에서 |

- 지금 테스트 서버(사무실 VM 두 대)는 **없애지 않고 "시험 서버"로 남긴다**. 배포 스크립트에 대상(시험 / 운영)을 고르는 옵션을 더해, 시험 서버에서 먼저 확인하고 운영에 올린다.
- 영상은 **app 서버가 직접 내보낸다** (`/media/*` ➔ Caddy ➔ data VM Garage). 그래서 **서버 인터넷 송신 요금 = 영상 전송 비용**이다. 이게 클라우드 선택에서 가장 큰 차이를 만든다.

### 3.3 방식 비교

| 방식 | 장점 | 단점 | 판단 |
|---|---|---|---|
| **VM 한두 대 + 지금 docker compose** | 시험 서버와 같은 구조. `deploy.sh` · 백업 · 복구 훈련 · 감시를 거의 그대로 씀. 비용 가장 낮음 | OS 업데이트 · 디스크는 우리가 챙김 (지금도 하는 일) | **베타 · 실오픈 초기 추천** |
| 관리형 DB · 객체 저장소 섞기 | DB 자동 백업 · 장애 대비. 저장소 용량 걱정 없음 | DB 월 1.5만 ~ 11만 원 추가 (Lightsail $15 · RDS $18 · NCP 11만 원 [2][3][6]). 영상이 Garage 웹 주소 ➔ Caddy 로 나가는 구조라, 객체 저장소로 바꾸면 영상 내보내는 부분(`server/videos.ts` · Caddy `/media`)을 다시 짜야 함. 백업 · 복구 스크립트도 새로 | 실오픈 뒤 사용자가 늘면 **DB 만** 다시 검토 |
| 컨테이너 서비스 (Lightsail 컨테이너 · Cloud Run · NKS 등) | 서버 관리 없음 | worker 의 긴 영상 변환, Garage, Caddy `forward_auth` 를 옮길 곳이 없음 ➔ 구조를 새로 짜야 함. 컨테이너 송신 포함분 500GB [1] | 하지 않음 |

## 4. 개인정보 · 법 (요약, 법률 검토 필요)

- 국외 이전은 개인정보보호법 제28조의8: 계약 이행에 필요한 처리위탁 · 보관이면 처리방침에 **① 항목 ② 국가 · 시기 · 방법 ③ 받는 자 · 연락처 ④ 목적 · 보유 기간 ⑤ 거부 방법** 을 공개하면 동의 없이 된다 [15].
- 개인정보보호위원회 안내서(2023.12)는 "해외 클라우드 서버에 보관 · 처리하면 국외 이전" 이라고 설명한다 [16]. **해외 회사의 서울 리전**에 대한 명시적 판단은 찾지 못했다. 통상은 국내 리전이면 국외 이전이 아니라 **처리위탁** 고지로 보지만, 해외에서 원격 지원 · 접근이 있으면 국외 이전으로 볼 여지가 있다 (추정).
- 그래서 Lightsail 을 쓰면 처리방침(`docs/정책초안/개인정보처리방침.md` 4장 · 5장, 이미 [검토] 표시 있음)에 **처리위탁: AWS(서버 · 데이터 보관, 서울 리전)** 을 적고, 국외 이전 칸까지 적을지는 법률 검토 때 함께 묻는다. 메일을 SES **서울**로 보내면 메일 주소도 서울 리전 안에서 처리된다. Resend · Postmark 같은 해외 메일 서비스를 쓰면 국외 이전 5개 항목을 적어야 한다 (추정).
- CSAP(클라우드 보안 인증)는 공공기관에 공급하는 클라우드 사업자용이라 민간 교육 사이트에는 필요 없다 (추정 [17]).
- 개인정보보호법 일부개정(2026-09-08 공포, 2027-03-09 시행 예정)이 있다. 제28조의8 이 바뀌는지는 확인 못함 [18].

## 5. 추천: AWS Lightsail 서울, VM 두 대 + compose

| 항목 | 내용 |
|---|---|
| app 서버 | Lightsail Linux 4GB · 2 vCPU · 80GB, 월 $24, 송신 4TB 포함 [1]. Caddy · web · worker · Gatus |
| data 서버 | 같은 크기 1대. PostgreSQL · Garage · 백업. **공인 포트는 열지 않음** (app 서버에서 사설 IP 로만) |
| 접속 막기 | Lightsail 방화벽: 80 · 443 은 모두, **22(SSH) 는 사무실 공인 IP 만**. data 서버 SSH 는 app 서버를 거쳐서. 관리자 화면은 Caddy 에서 사무실 IP 만 (`Caddyfile` 주석) |
| 메일 | Amazon SES 서울 SMTP (가입 인증 · 비밀번호 재설정 · 영수증 · 감시 알림 모두). 도메인 SPF · DKIM · DMARC 등록 |
| 백업 | ① 지금 `backup.sh` 를 그대로 돌리되 저장 위치를 data 서버 디스크로 ② **사무실 호스트가 매일 받아 와서** 지금처럼 `G:` ➔ `F:` (밖에 사본 하나, 운영자 손에 사본 하나) ③ Lightsail 자동 스냅샷 (매일, 7개) |
| 감시 | Gatus 는 app 서버에 그대로 + **사무실 시험 서버에 바깥 감시**(공개 주소 `/api/health` 와 인증서 만료) ➔ 클라우드가 통째로 멈춰도 알림 |
| 배포 | 빌드는 지금처럼 사무실 개발 VM. 개발 VM ➔ 클라우드 app 서버로 SSH 역방향 터널을 열어 보관소에서 **바뀐 층만** 받아 감. 배포 전 백업 · 마이그레이션 · 상태 확인 · 자동 되돌리기 그대로 |

**왜 이걸 고르나 (세 줄)**

1. **영상 비용이 거의 0원**: 서버 한 대에 월 4TB 송신이 들어 있고 같은 크기 서버끼리 합산된다 [2]. 다른 곳은 실오픈 2TB 에서 송신만 월 20만 ~ 40만 원 붙는다.
2. **지금 만든 것을 그대로 쓴다**: compose · Caddy · Garage · 백업 · 복구 훈련 · 감시 · 배포 스크립트를 주소와 경로만 바꿔 옮긴다. 컨테이너 서비스 · 관리형 서비스로 다시 짤 일이 없다.
3. **서울 리전 + SES 서울**: 국내 지연이 짧고, 메일까지 같은 리전에서 끝난다. 실오픈 때는 서버 크기만 올리면 된다 (토스는 서버 위치를 따지지 않음).

**알아 둘 점 (단점)**

- 달러 · 해외 카드 결제. 원화 세금계산서 처리 방식은 확인 못함 (운영자 확인).
- Lightsail 서버는 **버스트형 CPU** 다 (추정). 긴 영상 변환이 몰리면 느려질 수 있다 ➔ 그때 app 서버를 8GB($44)로 올린다.
- 사설 IP 로 오가는 트래픽은 **무료지만 포함분(4TB)에서는 깎인다** [2]. 영상 1GB 가 data ➔ app ➔ 사용자로 가면 포함분이 약 3GB 줄어든다. 그래서 두 대 합산 8TB 는 **영상 약 2.5TB** 쯤으로 보면 된다 (추정). 그 위로 커지면 ① 두 대를 한 대로 합치거나 ② 영상만 CDN 으로 내보낸다.
- 해외 회사라 처리방침에 위탁(필요하면 국외 이전) 고지를 법률 검토와 함께 정한다 (4장).

## 6. 대안: 네이버 클라우드 (같은 방식)

- **고를 때**: 원화 결제 · 세금계산서 · 국내 회사 고객지원 · 개인정보 해석의 단순함이 비용보다 중요하면.
- 구성: VPC 안 KVM High CPU-g3 2vCPU/4GB 두 대(66,240원 × 2) + SSD 디스크 + 공인 IP 1개 [5]. VPC 사설 IP 를 지금과 같은 `172.30.0.10 · .20` 으로 두면 compose · Caddyfile 을 거의 안 고친다. 메일은 Cloud Outbound Mailer(월 1,000건 무료) [6], 백업 사본은 Object Storage(28원/GB) 또는 사무실로 받아 옴.
- 신규 가입 크레딧 10만 원(3개월, 결제수단 등록 뒤 신청) [6]. 개인 계정으로 가입하고 나중에 사업자 계정으로 바꿀 수 있다 [19].
- 비용: 베타 약 17만 원, 실오픈 초기(2TB) 약 45만 원. 영상이 커지면 Global Edge CDN(84원/GB) [6].
- 주의: KVM Standard 는 2vCPU/8GB 부터라 2/4 는 High CPU 뿐이다 [20]. Cloud Outbound Mailer 가 2026-09 에 SENS 로 합쳐졌다는 요약이 있으나 원문 확인 못함.

> 오라클 무료 등급은 0원이지만 2026-06 에 한도가 절반(2 OCPU / 12GB)으로 줄었고, 춘천은 자리가 없어 못 만드는 보고가 있으며, 7일 동안 덜 쓰면 회수될 수 있어 [10] 베타 · 실오픈에 기대기 어렵다. Arm 서버라 이미지 빌드도 바꿔야 한다.
> Cloudflare Tunnel 은 0원 · 작업량 최소지만, 무료 요금제로 영상을 내보내는 것이 약관(2026-09-28 수정본)에 걸리고 [12], 한국 접속이 해외 거점으로 돌 수 있으며, 사무실 PC 한 대에 서비스 전체가 달린다. 실오픈으로 이어지지 않는다.
