# 베타 오픈 체크리스트 (지인 · 초대 수강생)

> M10 (2026-11-05). 베타는 **결제 없이** 운영자가 수강권을 발급해 초대한 사람만 받는다 (개발계획 2장: M3 이후 가능).
> 실결제 · 외부 공개(아무나 가입)는 이 목록 다음의 "실오픈" 이다.
> "누가": **운영자** = 운영자님이 해야 하는 일 (진행표 `docs/진행현황.md` 2장 운영자 대기와 같은 항목), **Claude** = 작업 창.
> 상태: 끝남 · 남음 · 운영자 대기

## 1. 베타 전에 꼭

| # | 무엇 | 누가 | 상태 | 비고 |
|---|---|---|---|---|
| 1 | 도메인 · 공인 IP (80 · 443 ➔ app VM), Caddyfile 사이트 주소를 도메인으로 (Let's Encrypt) | 운영자 결정 ➔ Claude | 운영자 대기 | 지금은 `https://localhost:18443` 터널로만 보인다. 지인이 밖에서 들어오려면 필요 |
| 2 | 메일 발송 서비스 (가입 인증 · 비밀번호 재설정 · 영수증 · 감시 알림) | 운영자 결정 ➔ Claude | 운영자 대기 | 지금은 Mailpit 에만 쌓인다. 정해지면 app VM `.env` 의 `SMTP_URL` · `MAIL_FROM`, 감시 `~/aionit-monitor/.env` 의 `MONITOR_SMTP_*` · `MONITOR_MAIL_TO` 를 바꾼다 |
| 3 | 감시 알림 받을 메일 주소 | 운영자 | 운영자 대기 | 감시는 켜져 있음 (Gatus, 멈춤 알림 확인함). 주소만 바꾸면 된다 |

| 7 | 관리자 화면 IP 대역 | 운영자 결정 ➔ Claude | 운영자 대기 | 도메인으로 밖에 열 때 함께 (Caddyfile 주석) |
| 8 | 보안 직접 점검 (`docs/보안점검.md` 2장) | 운영자 | 운영자 대기 | Claude 몫 점검 · 고침은 끝남 |
| 9 | 백업 · 복구 훈련 | Claude | 끝남 | 2026-11-05 빈 VM 복구 성공. 매달 반복 |
| 10 | 감시 · 알림 · 로그 회전 | Claude | 끝남 | 메일 주소(3)만 남음 |

## 2. 베타 진행

| # | 무엇 | 누가 | 비고 |
|---|---|---|---|
| 1 | 초대할 사람 목록 · 인원 | 운영자 | 처음에는 5 ~ 10명 추천 |
| 2 | 초대 안내 (사이트 주소, 가입 방법, 베타라 바뀔 수 있음, 의견 받는 곳) | 운영자 (문안은 Claude 가 초안) | 가입은 누구나 되므로 주소를 아는 사람만 들어온다. 막으려면 가입 제한 기능 필요 (지금 없음 ➔ 필요하면 말씀) |
| 3 | 가입한 사람에게 수강권 발급 (`/admin/users` ➔ 회원 ➔ 수강권 발급, 사유 "베타") | 운영자 | 기록에 남는다 |
| 4 | 의견 받기: 1:1 문의(`/my/inquiries`) 와 강의 Q&A | 운영자 | 따로 설문이 필요하면 외부 설문 링크를 공지에 |
| 5 | 매주 확인: 감시 상태 · 백업 기록 · 1:1 문의 · 오류 기록(추적 ID) | Claude · 운영자 | 감시 화면은 SSH 터널 (`infra/README.md` 감시) |
| 6 | 공지 · 자주 묻는 질문 실제 내용 | 운영자 | `/admin/notices` · `/admin/faqs` |
