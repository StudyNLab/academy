# AIONIT 개발 계획 (v0.1)

- 작성: 2026-11-03
- 일정: 정하지 않는다 (서두르지 않음). 대신 **단계마다 완료 기준**을 두고, 기준을 통과해야 다음 단계로 간다.
- 방식: 운영자와 Claude Code 가 함께 개발한다. 단계마다 테스트 서버(VM)에 올려 운영자가 직접 확인한다.

---

## 1. 단계 한눈에

| 단계 | 이름 | 끝나면 할 수 있는 것 |
|---|---|---|
| **M0** | 뼈대 · 개발 환경 · 배포 | 빈 사이트가 테스트 서버에 HTTPS 로 뜬다 |
| **M1** | 회원 | 가입 · 로그인 · 인증 메일 · 운영자 2단계 인증 |
| **M2** | 교재 올리기 · 강의 소개 | 교재 패키지를 올리고 검수해 공개, 강의 목록 · 상세가 보인다 |
| **M3** | 학습 | 수강권을 받은 사람이 학습 화면에서 공부하고 진도가 남는다 |
| **M4** | 유료 영상 | 자체 서버 영상을 수강생만 재생한다 |
| **M5** | 단건 결제 · 환불 | 테스트 결제로 강의를 사고, 환불을 요청 · 처리한다 |
| **M6** | 구독 | 구독 · 자동결제 · 해지 |
| **M7** | Q&A · 문의 · 알림 | 질문 · 답변, 1:1 문의, 사이트 알림 |
| **M8** | 강사 | 강사가 자기 강의를 올리고 현황을 본다 |
| **M9** | 정산 | 월 정산 계산 · 명세 · 지급 기록 |
| **M10** | 운영 준비 | 백업 · 복구 훈련, 감시, 보안 점검, 정책 문서, 베타 오픈 |

- M3 까지 끝나면 **결제 없이도** 운영자가 수강권을 직접 발급해 첫 강의(AI Agent 개발 · 초급)로 베타 수강생을 받을 수 있다.
- M8 (강사) 은 M5 이후 언제든 앞당길 수 있다.

## 2. 단계별 상세

### M0 · 뼈대 · 개발 환경 · 배포

| 할 일 | 완료 기준 |
|---|---|
| 모노레포 (pnpm · Turborepo), TypeScript strict, ESLint · Prettier | `pnpm lint` · `pnpm test` · `pnpm build` 통과 |
| 개발용 Docker Compose (PostgreSQL · Garage · Mailpit) | 명령 하나로 개발 환경이 뜬다 |
| `packages/db` 기본 스키마 + 마이그레이션 도구 | 빈 DB 에 마이그레이션 적용 성공. 되돌리기는 "배포 전 백업으로 복구" 또는 "고치는 새 마이그레이션"으로 한다 (Drizzle 은 되돌리기 마이그레이션을 만들지 않는다) |
| `packages/ui` 디자인 토큰 · 기본 부품 (Button, Field, 머리글) | 홈 화면 뼈대가 디자인 시스템대로 보인다 (라이트 · 다크) |
| 서버용 Compose (app VM: Caddy · web · worker / data VM: PostgreSQL · Garage · 레지스트리) | 두 VM 에 올라가 서로 내부망으로 통신 |
| 배포 스크립트 | 이 PC 에서 명령 하나로 테스트 서버에 배포 · 되돌리기 |
| 백업 기본 (DB 매일 ➔ G:) | 백업 파일이 생기고, 그것으로 복구해 본다 |

### M1 · 회원

| 할 일 | 완료 기준 |
|---|---|
| 이메일 가입 · 인증 메일 · 로그인 · 로그아웃 · 비밀번호 재설정 | 화면 흐름 테스트 통과 |
| 구글 로그인, 같은 이메일 계정 연결 확인(A-05). 카카오는 나중에 (2026-11-04 운영자 결정: 전체 구성 먼저) | 테스트 계정으로 확인 |
| 닉네임(고유 · 30일 변경), 약관 동의 기록, 만 14세 확인 | `user_consents` 에 버전과 함께 저장 |
| 역할(운영자 · 강사), 운영자 · 강사 2단계 인증 필수 | 2단계 인증 없이 `/admin` 진입 불가 |
| 로그인 횟수 제한, 로그인 기록, 관리자 작업 기록 | 제한 동작 확인, 기록 확인 |
| 회원 탈퇴 (개인정보 지우기 · 알아볼 수 없게 바꾸기) | 탈퇴 후 DB 에 개인정보가 남지 않는다 |

### M2 · 교재 올리기 · 강의 소개

| 영상 자리 ➔ 유튜브 주소 연결 (AD-05 일부) | 유튜브 영상이 교재 자리에 나온다 |

## 3. 진행 방식

- 단계마다: **계획 확인 ➔ 개발 ➔ 테스트 ➔ 테스트 서버 배포 ➔ 운영자 확인 ➔ 다음 단계**.
- 매 단계의 결과와 바뀐 결정은 `docs/` 에 남긴다 (`개발기록/M0.md` 등).
- 큰 변경 전에는 VM 스냅샷과 DB 백업을 먼저 받는다.
