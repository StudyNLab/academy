# 정책 문서 초안 (M10)

법률 · 세무 검토에 보낼 초안입니다. 같은 글이 테스트 서버에 `2026-11-06-draft` 버전으로 게시됩니다 (마이그레이션 0013). 검토가 끝나면 운영자가 **관리자 화면 ➔ 정책 문서**(`/admin/policies`)에서 검토본을 새 버전으로 올리고 시행일을 정합니다. 이 폴더의 파일은 검토 받는 사본이라 사이트가 읽지 않습니다.

| 파일 | 사이트 문서 (kind) | 가입 때 동의 | 검토 |
|---|---|---|---|
| `이용약관.md` | 이용약관 (`terms`) | 필수 | 법률 |
| `개인정보수집이용동의.md` | 개인정보 수집 · 이용 동의 (`privacy`) | 필수 | 법률 |
| `개인정보처리방침.md` | 개인정보처리방침 (`privacy_policy`, M10 새 종류) | 동의 아님 (공개 의무) | 법률 |
| `환불정책.md` | 환불 정책 (`refund`, 구독 포함) | 결제 · 구독 신청 때 | 법률 |
| `강사이용약관.md` | 강사 이용약관 (`instructor_terms`) | 강사 계약 때 | 법률 · 세무 |
| (그대로) | 마케팅 정보 수신 동의 (`marketing`) | 선택 | 법률 (짧음) |

표시:

- **[검토]** 법률 검토가 꼭 필요한 곳 (괄호 안이 물어볼 점)
- **[세무]** 세무사 확인이 필요한 곳 (`개발기록/M9.md` 의 세무사 확인 목록과 같이)
- **[입력]** 운영자가 채울 값 (상호, 대표자, 보호책임자, 메일 발송 서비스, 시행일)

## 검토할 때 함께 볼 것

- 사이트 바닥글의 사업자 정보(상호 · 대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 연락처)는 서버 설정 값(`.env` 의 `BUSINESS_INFO_*`)으로 넣는다 (`infra/README.md`).
- 결제 화면의 사전 고지 문구 (디지털콘텐츠 청약철회 제한): 강의 상세 · 구매 화면의 "7일 이내 · 이용 전 전액 환불" 안내.
- 탈퇴 화면 안내 (`/my/withdraw`): Q&A 글 존치, 1:1 문의 3년, 결제 기록 5년, 로그인 기록 6개월.

## 바꾸는 법 (관리자 화면)

1. `/admin/policies` ➔ 종류 고르기 ➔ 새 버전 (버전 이름 · 제목 · 내용 · 시행일).
2. 시행일은 내일 이후. 이용약관 · 개인정보 동의 · 환불 정책 · 강사 이용약관은 **7일 뒤 이후**, "회원에게 불리한 변경" 을 고르면 **30일 뒤 이후**만 받는다 (이용약관 제3조).
3. 시행 전에는 정책 화면에 "시행 예정" 으로 보이고, 지난 버전은 모두 남아 볼 수 있다. 시행 전 버전은 지울 수 있고, 시행된 버전은 고치거나 지울 수 없다.
